01 / Font

No webfont

和文 Web フォントを 1 本も読まない

CSS 全文の @font-face は 4 件だけで、うち 2 件が OS 同梱ヒラギノの別名宣言です。PostScript 名で W3（Regular）と W6（Bold）を名指しし、1 つのファミリー名に 2 ウェイトを束ねています。フォントファイルの実リクエストは 2 件で、どちらも自社ホストのアイコンフォント（vorkercon.ttf / vorkers-pc-icon.ttf）。和文は 1 バイトも落ちてきません。

この 2 行を省かないでください。省くと font-weight: 700 がブラウザの合成太字になり、W6 の字面と変わります。src が local() だけなので document.fonts 上は macOS で loaded、該当書体の無い環境では error になりますが、これは異常ではありません。
weight 400 → local(HiraginoSans-w3)

社員による会社評価スコア 2200万件のクチコミ

weight 700 → local(HiraginoSans-w6)

社員による会社評価スコア 2200万件のクチコミ

ウェイトはこの 2 段だけ（実測 400: 389 要素 / 700: 172 要素）。500 や 600 を当てても 400 で出ます。

サイズはすべて 13px を分母にした em

03 / Letter-spacing

Normal everywhere

字間を設計していない。例外はヒーローだけ

letter-spacing の宣言は CSS 全文で 12 件、可視要素の実測は normal が 557/561 要素です。唯一の例外がヒーローの大見出し 4 要素の 4px（69.875px に対して約 0.057em）。本文に字間を足さないでください。

letter-spacing: normal（実装）

letter-spacing: .05em（やってはいけない）

行間は body に line-height: 1.666 を無単位で 1 回だけ書いて継承させます。実測の行間比は 1.67 が 509/561 要素。例外は 1.60（タグ 18）・1.50（ボタン 15）・1.80（職種リンク 14）・1.30（ヒーロー 4）です。

07 / Responsive

No breakpoints

メディアクエリが 1 件も無い PC 専用ページ

1920 / 1440 / 1280 / 1200 / 1024 / 992 / 991 / 834 / 769 / 768 / 767 / 600 / 480 / 375 / 374px の 15 幅すべてで html: 16px / body: 13px / h2: 21.9999px / h3: 16.0004px が 1px も動きません。CSS 全文にメディアクエリが存在せず、スマートフォンは別テンプレートで配信されます。本文カラムは 1000px 固定です。

CSS Custom Property も 1 個もありません。:root にも body にも宣言が 0 個で、色もサイズも hex と em の直書きです。デザイントークンという層が存在しません。
font-feature-settings も CSS 全文に 0 件。ヒラギノ角ゴシックは palt を持つので効かせられますが、既存のレイアウトは詰めない前提で組まれています。
