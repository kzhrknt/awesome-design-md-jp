04 / Letter Spacing
宣言はあるが、事実上ゼロ

body の -0.001em は再現しなくてよい

body { letter-spacing: -0.001em } が 13px に対して -0.013px という絶対値になり、206 / 112 要素へ px のまま降りる。32px の見出しでも -0.013px のまま（= -0.0004em）なので、大きい文字ほど「何もしていない」。

型実測仕組み
継承型（既定）-0.013px が 206 / 112 要素body の -0.001em が 13px で絶対値になり、全子孫へ px のまま降りる
要素が em を持つ型16px → 2.24px ／ 32px → 4.48px下層の節見出し・ページタイトルだけ 0.14em を自分で宣言している
継承型 ─ letter-spacing: -0.013px（実質ゼロ）
大学概要
要素が持つ型 ─ letter-spacing: 0.14em（本当に意味がある字間）
大学概要
body に em の字間を書いて継承させないこと。13px の -0.001em は -0.013px という絶対値で降り、見出しで効かなくなる。本当に意味がある字間は下層見出しの 0.14em だけなので、その要素に em で書く。

font-feature-settings の宣言は CSS 全文に 0 件、実測も 0 要素。palt を足さない。YakuHanJP のような約物サブセットも使っていない。
