## 7. Do's and Don'ts

### Do（推奨）

- **`html { font-size: small }` ＋ `body { font-size: 124% }` を使い、サイズはすべて `%` で積む**
- **見出し・ナビ・CTA ラベルまで游明朝で組む**
- **見出しに `letter-spacing: 0.2em`、ナビに `0.1em`、ヒーローに `0.6em`** を各要素が `em` で宣言する
- **`font-weight` は 400 のまま使う**（太字を足さない）
- **本文の `line-height` は 1.80**
- **本文の `<span>` に `font-feature-settings: "palt"`** を当て、見出しには当てない
- **本文カラムは `max-width: 550px`** に絞る
- **写真の上の白文字は `text-shadow: rgba(0,0,0,.4) -2px 0 0`**（ぼかしゼロ・片側）
- **CTA は `#5ea4bf` / radius 3px / padding 8px 16px / weight 400**

### Don't（禁止）

- **`font-size` を px で書かない。** `small` キーワード＋`%` の連動が壊れる
- **`font-weight: 700` を足さない。** 可視 233 要素中 232 要素が 400。合成太字でサイトの質感が変わる
- **`letter-spacing` を `body` にまとめて書かない。** `body` は `normal` で、字間は要素ごとに `em`
- **ヒーローの字間を 1 つの値で書かない。** 0.6em / 0.1em / 0.45em の 3 段ある
- **`-2.5px` の負の字間を設計として真似しない。** カルーセルのラベルを幅に押し込む応急処置
- **`YuGothicM` をスタックの後ろに置かない。** `游ゴシック` より前に出さないと届かない
- **和文 Web フォントを足さない。** フォント要求は 2 件（Font Awesome と gstatic）だけ
- **縦組みを実装しない。** `writing-mode: vertical-*` は 0 件
- **純黒 `#000000` を本文・見出しに使わない。** 本文 `#464646` / 見出し `#010101`
- **`palt` を見出しに当てない。** 見出しは詰めずに `0.2em` 空ける
