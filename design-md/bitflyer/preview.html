05 / Layout & Guidelines

rootは10px、境界は690と1280

html { font-size: 10px } なので変数の rem はすべて ×10 が px（--spacing-4x: 1.6rem = 16px、--font-size-320: 3.2rem = 32px）。ブレークポイントは 690px と 1280px の 2 本で、中間帯を (691px <= width <= 1279px) の range 構文で直接書く。コンテナは 1170px、本文カラムは 620px。

Do

  • 数値を出す要素に必ず font-feature-settings: "tnum"（366 要素）
  • 数字は Nunito, sans-serif に切り替える
  • 60px 級の実績数字は Poppins 600 / letter-spacing: -5.6px
  • 和文の font-weight 既定を 600 にする（400 は注記のみ）
  • font-family は "Noto Sans JP" を先頭に置く
  • 数値・ラベル・ボタンは line-height: 1.00、本文は 1.75
  • CTA は #0050d7 / radius 12px / padding 0 24px / 影なし
  • タグは radius 990px のピル（面 #eef4ff、文字 #0050d7）
  • 地色は青い白を 3 段。値上がり青 / 値下がりオレンジ
  • 影は rgba(16, 42, 75, 0.06)

Don't

  • --primary-color-bg（#1980e5）を CTA に使わない
  • --color-text（#242428）を本文色にしない
  • ruby / emerald / yellow / red のパレットを使わない
  • 値上がりを赤、値下がりを緑にしない
  • 日本語に letter-spacing を足さない
  • palt を全体に足さない（実測 6 要素のみ）
  • Noto Sans JP の weight 300・可変指定を使わない（unloaded）
  • CTA に box-shadow を足さない
  • 影を rgba(0,0,0,…) にしない
  • body の font-family 宣言（-apple-system 先頭）を真似しない

トップページと下層ページは別のデザインシステム。トップは "Noto Sans JP" 先頭・weight 600 既定・radius 12px・コンテナ 1170px。下層 /s/how-to-start は -apple-system 先頭・weight 400 既定・radius 4px・コンテナ 1080px で、可視 101 要素すべてが body のスタックのまま。新規に組むならトップ側（新しい世代）に合わせる。
