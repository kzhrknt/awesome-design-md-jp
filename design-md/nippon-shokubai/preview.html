02 / LETTER SPACING

0.03em を 1 行だけ。大きい文字ほど薄まる

body に letter-spacing: 0.03em を 1 回書くと、0.48px という絶対値が全子孫へ降りる（可視 117 要素中 110 要素）。font-size が違っても px は同じなので、em 換算するとサイズごとにばらつく。それでいいという設計。

palt は効く。それでも使っていない

CSS 全文に font-feature-settings が 1 件も無い（実測も 0 要素）。だが同一ページ・同一書体（Noto Sans JP）での実測は normal 868.75px → "palt" 773.80px の −10.9%。書体が持っていないのではなく、使っていない。足すと 0.03em で作った字送りが別物になる。

03 / LINKS

下線はグラデーションで引く

グローバルナビのリンクは text-decoration: none のまま、背景のグラデーションで 1px の下線を引いている（可視 14 要素）。background-size を 0 100% → 100% 100% に伸ばすことで、下線が左から伸びるホバーになる。

06 / RESPONSIVE

html は 16px 固定、body だけ落ちる

html { font-size } の宣言自体が無く UA 既定の 16px。切り替わるのは body だけで、境目は 768 / 767px の 1px。834px も 375px も測るだけでは段差が見えない。

幅htmlbody font-sizeline-heightletter-spacing
1920 / 1440 / 1200 / 1024 / 834 / 768px16px16px24px0.48px
767 / 414 / 375 / 374px16px15px22.5px0.45px

line-height: 1.5（無単位）も letter-spacing: 0.03em もどちらも追従する。letter-spacing を px に読み替えて書くとモバイルで字間が合わなくなる。

メディアクエリの最頻は screen and (min-width: 768px), print（237 回）。print を抱き合わせているので、印刷時はデスクトップ版のレイアウトになる。
