01 / Fluid Root

max-width を持つコンテナが1つも無い

04 / Letter Spacing
字間Spacing

0.03em を body に1回。ただし px 自体が画面幅で動く

body { letter-spacing: 0.03em } は root 16px のとき 0.48px という絶対値になり、そのまま子孫へ降りる（実測 145 要素）。サイズに比例しない。さらに html が vw 流体なので、この px 値自体が画面幅で動く。
