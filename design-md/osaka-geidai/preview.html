01 / Font

One family

書体の変数が 3 つあるのに、中身が全部同じ

--font-family-main / --font-family-hind / --font-family-midashigo の 3 つとも値は 'Zen Kaku Gothic New', sans-serif です。名前が示すはずの Hind（欧文）も A-OTF 見出ゴ MB31 Pr6N も、実体として当たっていません。しかも --font-family-main は参照 0 回です。

Adobe Fonts の「A-OTF 見出ゴ MB31 Pr6N」を読み込んだまま、1 要素も使っていません。 Typekit（use.typekit.net/rst6btm.js）経由で a-otf-midashi-go-mb31-pr6n が document.fonts 上 loaded になり、フォントファイルの要求も実際に発生します。それでも呼び出しは Typekit が吐く .tk-a-otf-midashi-go-mb31-pr6n クラスだけで、可視要素の書体は 2 ページとも Zen Kaku Gothic New が 124/138 要素。CDP の CSS.getPlatformFontsForNode でも全要素 Zen Kaku Gothic New が返ります。変数名から書体を推測せず、見出ゴを実装しないでください。

02 / Colors

One accent

蛍光イエローが 183 回、ピンクが 25 回。彩度のある色は 2 つだけ

04 / Typography

Size pairs

サイズと行送りを「対で」選ぶ。比率で掛けない

--fontsize-m: 18px に --fontline-m: 30px が対応します（比率 1.67）。clamp() は使わず、SP では --fontsize-sp-m: 16px と変数名ごと差し替えます。body の line-height は 16.1px（= 14px × 1.15）で、これは normalize 由来の既定値。各要素が宣言し直さないと行が詰まります。

字間は px の直書き

CSS の宣言 82 件のうち 81 件が px（0.33px 0.4px 0.5px 0.6px 0.7px 0.8px 1px 1.1px 1.8px 4px）、em は 0.05em の 1 件だけ。ページによって配り方が正反対で、トップは 0.4px が 60 要素、下層は normal が 115/138 要素です。1 ページだけ測って「このサイトの字間」と書かないでください。

05 / Components

No radius

ボタンもカードも角を丸めない

border-radius はトップが 2px 31 要素（カテゴリタグ）とロゴの 50px 1 件、下層は 50% 1 件だけ。box-shadow は 2 ページとも 0 種で、立体感を一切作りません。ホバーは色を変えず opacity: .8 に落とします。

06 / Spacing

Eight steps

余白は --margin-* の 8 段から選ぶ

実測の gap は 20px 3 件 / 18px 32px 2 件 / 16px 1 件 / 4px 1 件しかありません。Flexbox の gap ではなく --margin-* で間隔を作ります。既定は --margin-m: 64px（参照 75 回で最多）。コンテナは --layout-inner: 1280px（参照 24 回）です。

--margin-xmini 8px（13 回）
--margin-mini 16px（53 回）
--margin-xxs 24px（23 回）
--margin-xs 32px（17 回）
--margin-s 40px（51 回）
--margin-m 64px（75 回・最多）
--margin-l 80px（11 回）
--margin-xl 120px（7 回）
本文に康熙部首を混ぜないでください。実サイトのニュース見出しに ⼤（U+2F24・康熙部首）が 2 件混入しています（「モレスキン×⼤阪芸術⼤学共同プロジェクト」）。字形はほぼ同じですが、検索・コピー・読み上げが壊れます。通常の「大」（U+5927）で書いてください。
07 / Responsive

Fixed root

ルートは流体ではない。幅ごとに変数名を差し替える

html: 16px / body: 14px は 1920〜374px の 15 幅で 1px も動きません（html に font-size の宣言が無く UA 既定のまま）。主なブレークポイントは (max-width: 767px) 7 件 / (min-width: 768px) 4 件 / (max-width: 1280px) 4 件。orientation: landscape のクエリを 7 件持つのが珍しく、キャンパスマップの表示を縦横で変えています。
