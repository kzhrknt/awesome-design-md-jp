07 / Elevation
Elevation

実効する box-shadow は 2 種類だけ。カードもボタンも Level 0。

Level 0 — 既定box-shadow: none;
Level 1 — 固定ヘッダー0 1px 2px 0 rgba(0,0,0,.16)
Level 2 — 入力欄の内側罫inset 0 -1px 0 rgba(0,0,0,.25)

影を足すと別のサイトになる。奥行きは #f8f8f8 の面と #d9d9d9 の 1px 罫で表現する。
