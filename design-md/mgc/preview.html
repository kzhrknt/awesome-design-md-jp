01 / OpenType

書いてある pwid は、効いていない

実サイトは body { font-feature-settings: "pwid" } を 1 行書いて 1172 要素へ継承している（html は normal）。しかし実スタック・40px で測ると、実際のページ文面では 1px も変わらない。唯一動くのは約物が連続したときで、しかも詰まるのではなく 27.9% 広がる。詰めたいなら palt。

font-feature-settings が宣言されていることと、効いていることは別。このサイトは「palt が効かない」のではなく、palt ではなく pwid を書いてしまっている。既存ページと見た目を揃えるなら pwid のままにし、詰めたいときだけ palt に差し替える（その瞬間に全ページの折り返しが変わる）。

03 / Typography

字間は body に 1 回だけ

body { letter-spacing: 0.05em } が 16px × 0.05 = 0.8px の絶対値で全子孫に降りる（可視 136 / 110 要素）。サイズが変わっても 0.8px のままなので、24px の見出しでは 0.033em、12px のキャプションでは 0.067em。大きい文字ほど字間が相対的に消える。ヒーローだけ負の -2.6px で、これも 26px の親から 46px の子へ px のまま降りる。

07 / Spacing & Container

--spaceSS から --spaceXL まで 7 段

自社トークン 16 個のうち 7 個が余白。--spaceTtl: 48px だけスケールから外れた用途名なので、見出し直下の余白はこれを使う。コンテナは最外 1700px／本文 --contensWidth: 1300px／左右 --bothSides: 4.8%。contens という綴りは直さない（参照が切れる）。
