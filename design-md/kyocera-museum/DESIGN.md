# DESIGN.md — 京都市京セラ美術館（Kyoto City KYOCERA Museum of Art）

> 京都市京セラ美術館（https://kyotocity-kyocera.museum/）のデザイン仕様書。
> 1933 年開館、日本で現存する最古の公立美術館建築。2020 年に青木淳・西澤徹夫の設計でリニューアルオープンした。
> 最大の特徴は、**和文をモリサワの写植由来ゴシック 2 書体だけで組む**こと。**UI・本文は「中ゴシック BBB」、大見出しは「太ゴ B101」**で、この 2 つ以外の書体を一切使わない。欧文専用スタックも持たない。
> 色は白地に**朱 `#c83c1e`**（チケット導線）と**墨 `#333333``**（それ以外すべて）。加えて、**金茶 `#917d43` / `#b69f59` / `#cec093` の三段の金**が、開館情報・カレンダー帯・見出しに現れ、美術館らしい落ち着いた華を作る。
> **`box-shadow` は 1 つも使わない**。奥行きは面色と 1px の罫だけで作る。
> 実サイトの computed style 実測（2026-08-11 取得。トップ＋「自主・共催の展覧会」ページ）に基づく。

## 1. Visual Theme & Atmosphere

- **デザイン方針**: **白地・角丸ゼロ・影ゼロ**。展覧会のポスター画像が主役で、UI は完全に脇役に徹する。画像の色数が多いぶん、UI 側は墨と朱と金だけに絞る
- **京都市京セラ美術館について**: 1933 年開館の公立美術館。帝冠様式の本館に現代的なガラスリボンを差し込んだ建築で知られる。サイトも「古い器に新しい中身」を踏襲し、**書体は写植時代のモリサワ、レイアウトはフラットな現代 UI** という組み合わせ
- **密度**: 中〜高密度。トップは展覧会カルーセル → カレンダー → お知らせ の積層。展覧会カードは画像・バッジ・タイトル・会期・会場の 5 要素を詰めて並べる
- **キーワード**: 白地、中ゴシック BBB、太ゴ B101、朱 `#c83c1e`、墨 `#333333`、三段の金、radius 0 の矩形バッジ、影なし
- **特徴**:
  - **和文はモリサワの 2 書体のみ**。`a-otf-gothic-bbb-pr6n`（**中ゴシック BBB**）が UI・本文、`a-otf-futo-go-b101-pr6n`（**太ゴ B101**）が大見出し。どちらも写植時代からの基幹ゴシックで、**ふところが狭く縦画が締まった古典的な骨格**
  - **欧文専用のスタックを持たない**。"Exhibitions" "Calendar" も同じ和文書体の欧文グリフで組まれる
  - **`letter-spacing` が全要素 `0.625px` の固定値**。em ではなく px で body に置き、そのまま継承させている。10px では 0.0625em、32px では 0.0195em と、**サイズが上がるほど相対的に締まる**
  - 例外は**太ゴ B101 の見出しだけが `0.1em`（32px → 3.2px / 28px → 2.8px）に開く**こと。書体の切り替えと字間の開きが同時に起きる
  - **`line-height` の基準は 1.8**（10px → 18px / 16px → 28.8px）。大見出しだけ 1.5 に締める
  - **`box-shadow` は 1 つも使わない**（実測 0 件）
  - **主要 CTA だけが朱 `#c83c1e`**。それ以外のボタン・バッジはすべて墨 `#333333` の塗りか枠
  - **`palt` は掛けない**（`font-feature-settings: normal`）
  - CMS は WordPress だが、テーマの CSS 変数はほぼ既定値のまま。**色は変数化されておらず、実測値がすべて**

## 3. Typography Rules

> **モリサワの写植由来ゴシック 2 書体だけで組む**。中ゴシック BBB が UI・本文、太ゴ B101 が大見出し。`letter-spacing` は **px の固定値 0.625px を全体に継承**させ、**太ゴの見出しだけ 0.1em に開く**。

### 3.1 和文フォント

- **本文・UI**: **中ゴシック BBB**（`a-otf-gothic-bbb-pr6n`）。モリサワの写植時代からの基幹ゴシック。**ふところが狭く、縦画が締まり、小さく組んでも字面が崩れない**。Pr6N は Adobe-Japan1-6 / JIS2004 字形
- **大見出し**: **太ゴ B101**（`a-otf-futo-go-b101-pr6n`）。中ゴシック BBB と対になる太ゴシック。**角が立ち、ふところがさらに狭い**ため、大きく組むほど写植らしい強さが出る
- **フォールバック**: `sans-serif` のみ。**`"a-otf-gothic-bbb-pr6n", sans-serif` という 2 段の極端に短いチェーン**で、Web フォントが当たることを前提にしている
- ヒラギノ・游ゴシックを経由しない。**Adobe Fonts が読み込めない環境ではシステム既定のサンセリフに落ちる**割り切った設計
- **実装時は必ず Adobe Fonts のキットを読み込むこと**。フォールバック側の設計がないため、外れると印象が大きく変わる

### 3.2 欧文フォント

- **欧文専用のスタックを持たない**。"Exhibitions" "Calendar" "HOME" などの英字も**中ゴシック BBB / 太ゴ B101 の欧文グリフ**で組む
- そのため和欧のトーンが完全に揃う。欧文だけ浮くことがない
- 等幅フォントは使わない
- **preview.html での注記**: `a-otf-gothic-bbb-pr6n`（中ゴシック BBB）/ `a-otf-futo-go-b101-pr6n`（太ゴ B101）は Adobe Fonts のドメインライセンスのため、ローカルの preview.html では表示できない。プレビューでは **Google Fonts の `Zen Kaku Gothic New`（400 / 500 / 700）** を代替に用いる。Zen Kaku Gothic New は**モリサワ提供の書体**で、中ゴシック BBB と同じ提供元・近い骨格のため印象が最も近い。実装時は必ず Adobe Fonts を読み込むこと

### 3.3 font-family 指定

```css
/* 本文・UI（中ゴシック BBB） */
font-family: a-otf-gothic-bbb-pr6n, sans-serif;

/* 大見出し（太ゴ B101） */
font-family: a-otf-futo-go-b101-pr6n, sans-serif;

/* body の既定 */
font-size: 16px;              /* ルート。10px はフッター等の最小指定 */
font-weight: 400;
line-height: 1.8;             /* 16px → 28.8px */
letter-spacing: 0.625px;      /* em ではなく px の固定値。全体に継承させる */
color: #333333;
font-feature-settings: normal;  /* palt は使わない */
```

**フォールバックの考え方**:
- **チェーンを伸ばさない**。`sans-serif` で即座に締める
- **ウェイトは 400 / 500 / 700 の 3 段のみ**。太ゴ B101 は 500、中ゴシック BBB の強調は 700
- **太さの切り替えと書体の切り替えを重ねる**。大見出しは「太ゴ B101 + weight 500 + ls 0.1em」の 3 点セットで作る

- ウェイトは **400 / 500 / 700** の 3 段。**500 は太ゴ B101 専用**

### 3.5 行間・字間

- **本文の行間 (line-height)**: **1.8**（16px → 28.8px）。日本語サイトとしても広めで、白地の余裕を作っている
- **見出しの行間**: 大見出しは **1.5**（32px → 48px）に締める。太ゴ B101 の 28px 見出しだけ 1.8 のまま
- **バッジの行間**: **1.2**（10px → 12px）。極端に締めて小さな矩形に収める
- **字間 (letter-spacing)**: **全体に `0.625px` を継承**させる方式
  - 本文 16px: 0.625px（= 0.039em）
  - 最小 10px: 0.625px（= 0.0625em）— 小さいほど相対的に開く
  - **太ゴ B101 の見出し: 0.1em**（32px → 3.2px / 28px → 2.8px）
- **`palt` は使わない**（`font-feature-settings: normal`）

**ガイドライン**:
- **字間は px の固定値で通す**。em に変換して「見出しほど締める」設計に変えないこと。小さい文字ほど開き、大きい文字ほど締まるのがこのサイトの手触り
- **太ゴ B101 に切り替えるときだけ 0.1em に開く**。書体・ウェイト・字間の 3 つを同時に切り替える
- 本文 1.8 を下回らない。詰めると白地の余裕が消える
- バッジは 1.2 まで締めてよい（矩形の高さを抑えるため）

### 3.6 禁則処理・改行ルール

```css
overflow-wrap: break-word;
line-break: strict;
word-break: normal;
```

**禁則対象**:
- 行頭禁止: `）」』】〕〉》、。，．・：；？！`
- 行末禁止: `（「『【〔〈《`

- 展覧会名は『浮世絵スーパークリエイター 歌川国芳展』のように長く、括弧・中黒・全角スペースを含む。**括弧の前後と会期の「-」の前後で改行させない**
- 会期表記（`2026年07月18日 - 2026年09月23日`）は 1 行に収め、折り返す場合は `-` の後で折る

### 3.7 OpenType 機能

```css
font-feature-settings: normal;   /* palt を掛けない */
```

- **`palt` は使わない**。中ゴシック BBB・太ゴ B101 の等幅の字面をそのまま使う
- **写植由来の書体は元々ふところが狭い**ため、`palt` で詰めると窮屈になる。字間は `letter-spacing` を開く方向でのみ調整する
- 和欧が同一書体（和文書体の欧文グリフ）なので、`kern` に頼らずとも混植が破綻しない

### 3.8 縦書き

- 現行サイトは全面横組み（`writing-mode: horizontal-tb`）
- 展覧会ポスターや作品キャプションで縦組みを見せる場合は以下

```css
writing-mode: vertical-rl;
text-orientation: mixed;
font-family: a-otf-gothic-bbb-pr6n, sans-serif;   /* 縦組みも同じゴシックで通す */
letter-spacing: 0.1em;   /* 縦組みでは開く */
```

- **明朝に切り替えない**。このサイトは明朝を一切使わないため、縦組みもゴシックで通す

## 5. Layout Principles

### Spacing Scale

## 6. Depth & Elevation

**実測の `box-shadow` は 0 件**。このサイトは影を一切使わない。

| Level | Shadow | 用途 |
|-------|--------|------|
| 0 | `none` | **すべて**。白地・面色・1px の罫だけで構成する |
| — | `rgba(33,33,33,0.9)` | モーダル背後のスクリム（影ではなくオーバーレイ） |

- 奥行きは **白 `#ffffff` × 墨 `#333333` × 金茶 `#917d43` の面**と**1px の罫（`#cccccc` / `#858585`）**のコントラストだけで表現する

## 7. Do's and Don'ts

### Do（推奨）

- 和文は**中ゴシック BBB（UI・本文）と太ゴ B101（大見出し）の 2 書体だけ**で組む
- **欧文も同じ和文書体の欧文グリフ**で組む。欧文専用のスタックを足さない
- **`letter-spacing` は `0.625px` の px 固定値**を body に置き、全体に継承させる
- **太ゴ B101 に切り替えるときだけ `0.1em` に開く**。書体・weight 500・字間を同時に切り替える
- 本文の行間は **1.8**、大見出しは 1.5、バッジは 1.2
- 彩度は**朱 `#c83c1e`（チケット導線）と金茶の三段**に絞る
- テキストは墨 `#333333`（純黒ではない）
- ボタン・バッジ・カード・画像は**すべて radius 0**
- **影を使わない**。面色と 1px の罫だけで構成する
- 展覧会カードは「枠バッジ＋塗りバッジ」の 2 つを横に並べる
- 墨面に金の文字（`#333333` × `#b69f59`）で「格」を作る
- **Adobe Fonts のキットを必ず読み込む**（フォールバックが `sans-serif` だけのため）

### Don't（禁止）

- **明朝を使わない**（このサイトは全面ゴシック。縦組みでも明朝に切り替えない）
- **3 つ目の和文書体を足さない**（中ゴシック BBB と太ゴ B101 だけで階層を作る）
- **欧文専用フォント（Helvetica / Futura 等）を足さない**（和欧のトーンが崩れる）
- **`letter-spacing` を em に置き換えない**（見出しほど締まる px 固定の手触りが失われる）
- **朱 `#c83c1e` をチケット以外に使わない**（唯一の暖色 CTA としての意味が薄れる）
- **角丸を使わない**（radius が許されるのは検索・言語切替の `5px` のみ）
- **影を作らない**（`box-shadow` の実測は 0 件）
- `palt` を掛けない、字間を詰める方向に動かさない
- 純黒 `#000000` を使わない（テキストは墨 `#333333`）
- 金茶を広い面に多用しない（`#917d43` はセクション帯 1 箇所に限定する）
- 本文の行間を 1.5 以下にしない
- カードを枠線で囲まない（ガターだけで区切る）

## 8. Responsive Behavior

### Breakpoints

| Name | Width | 説明 |
|------|-------|------|
| Mobile | ≤ 767px | 1 カラム。グローバルナビはドロワー、朱の CTA は下部固定に回る |
| Tablet | 768–1024px | 2 カラム。展覧会カルーセルは 2.5 枚見せ |
| Desktop | > 1024px | 5 カラムのカルーセル＋最大 1280px コンテナ |

### タッチターゲット

- 最小サイズ: 44px × 44px（WCAG 基準）。10px のバッジ（padding 6.5px）は装飾なので対象外、展覧会カードは**カード全体をタップ領域**にする
- カレンダーのセルは 1 日あたり最低 44px 幅を確保し、横スクロールさせる
- 朱の CTA はモバイルで高さ 48px の下部固定バーにする

### フォントサイズの調整

- 本文 16px は据え置く（14px を下回らない）
- 太ゴ B101 の Page Title 32px → モバイルでは 22〜24px。**`letter-spacing: 0.1em` は維持する**
- 金茶帯の Section Title 32px → 22px
- バッジ 10px・キャプション 10px は縮めない
- **`letter-spacing: 0.625px` の固定値と行間 1.8 はモバイルでも維持する**
