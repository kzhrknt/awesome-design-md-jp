CAUTION再現するときの注意

1. letter-spacing を書かない。 実測 100% が normal。0.05em を足すと別のサイトになる。

2. palt をデスクトップに足さない。 実サイトは 1440px で 0 件。効かないのではなく、使っていない（Noto Sans JP の実測で normal 1291px → "palt" 1131.4px）。足すと既存の見出しと字送りが揃わなくなる。

3. ヒーローの大コピーを Web フォントで実装しない。 SVG にアウトライン化されていて、「膜」の 2 文字だけ #004bb4 に塗り分けられている。

4. alt を画像の文字と食い違わせない。 実サイトは alt="膜にこだわり、膜を越える。"／画像は「膜を超える。」。

5. --wp--preset--* / --wp-admin-* を採用しない。 CSS 変数 63 個のうち 60 個が WordPress の既定値で、実装には使われていない。
