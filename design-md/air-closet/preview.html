06 / Responsive

ルート 1 行で全体が 1.8 倍に伸び縮みする

html { font-size: 18px }（680px 以上）と html { font-size: 2.67vw }（680px 未満）の 2 段だけ。サイズ・余白・角丸・影がすべて rem なので、この 1 行で全部が追従する。

18 / 10.0125 = 1.798。デスクトップ（680px 以上）は 375px の設計を 1.8 倍に拡大したものとして読む。 680 → 679px でわずかに上へ跳ねる（18 → 18.1293px、+0.7%）のは、2.67vw が 18px に一致するのが 674.2px で、 切り替え点の min-width: 680px と 6px ずれているため。崖というより段差で、見た目の破綻は無い。

ブレークポイントは screen and (min-width: 680px) がルートを切り替える唯一の境目。 ほかに (max-width: 1156px) / (max-width: 823px) / screen and (max-width: 820px) / (max-width: 480px) / screen and (max-width: 375px) / (hover: hover) and (pointer: fine) がある。 font-size をメディアクエリで直接いじる箇所は 1 つも無い。 px 直書きは規約リンクの 15px とコピーライトの 14px の 2 箇所だけで、ここだけがモバイルで追従しない。
