字間は各要素が em を持つ。 50px → 5px、26px → 2.6px、14px → 1.4px とサイズに比例して px が変わる（= どれも 0.1em）。body からの px 継承ではない。

--font_family_en: 'Inter', sans-serif は使わない。 フォントを調達していないので sans-serif に落ちる。可視要素も 0。欧文は Barlow（weight 200 と 700 の 2 段）だけ。

実サイトの誤り（並記）: letter-spacing: 1.5（単位なし）という宣言が 1 つあるが、単位なしの数値は無効なので効いていない。1.5px か 0.1em のつもりだったと思われる。

05 / Responsive
Width

ルートは19幅すべてで1px

html 1px / body 16px は 1920〜320px の 19 幅すべてで動かない。h2 も 24px、p も 15px のまま。流体も clamp() も崖も無い。CSS 内に body { font-size: 14rem } があるが、19 幅のどれでも到達しない。

ブレークポイントは print, screen and (min-width: 1000px) が 10 件で最多。ほかに 1560 / 1400 / 1365 / 1279 / 1169 / 999 / 767 / 499px。min-width 基準と print, の併記がこのサイトの癖。

--header_h は 100px → 70px に切り替わる。言語切替（JP / EN）は height: 22px でモバイルも同じなので、44px 基準を満たさない。

ヒーローは three.js の <canvas>（2020×1405・data-engine="three.js r153"）。「BUILD NEXT.」は mv_logo.svg（529×49・alt="BUILD NEXT"）の画像で、その下の「ビルを造り、街を創り、時代を拓く」だけが実テキスト。ロゴタイプを Barlow で組み直さないこと。
