bodyfont-size: var(--FONT_SIZE)。既定 0.875rem（14px）、@media (min-width: 768px) でだけ 1rem（16px）

字間書かない。可視 172 要素中 163 要素が normal。足すのは英字見出しの 1px とヒーローのリードの 0.8px だけ
字詰めbody に font-feature-settings: "halt" を 1 行だけ。可視 153 要素 / DOM 全体 598 要素へ継承（下層 427 要素）
書体Roboto, "Noto Sans JP", "Noto Sans SC", "Noto Sans TC", "Noto Sans KR", sans-serif の 1 スタックのみ。セルフホストで @font-face 482 本
CSS 変数自社トークン 53 個（UPPER_SNAKE 命名）。うち色の 8 個は 2 ページとも可視 0

NOTES

再現するときの注意

字詰め"halt" を "palt" に置き換えない。halt は全角の約物を一律に半角幅へ揃える機能で、文字ごとに詰め幅を変える palt とは別物。palt は 1 要素も使っていない
字間em で全体に配らない。このサイトは字間を触らないのが設計。足す 2 箇所も px の絶対値
書体の読み方getComputedStyle が返す font-family の先頭は常に Roboto だが、和文を描いているのは Noto Sans JP。第 1 項を「描画されている書体」と読まない
多言語スタックSC / TC / KR は宣言だけで日本語ページでは読まれない（loaded は JP と Roboto のみ）。日本語だけなら Roboto, "Noto Sans JP", sans-serif で足りる
使わない色--COLOR_BRAND_SUB_1..5（#651366 #001c77 #005180 #005777 #8c003d）--COLOR_ROLE_IMPORTANT: #f9827c --COLOR_TEXT_PLACEHOLDER: #9fa19c --LINER_GRADIENT（水色→薄紫）は2 ページとも可視 0
変数名グラデーションの変数は実サイトのまま --LINER_*（LINEAR ではない）。6 つすべてこの綴り
英字見出しの色#474C59 は CSS 変数に無いハードコード。ブランド色ではない
CMPOneTrust が画面下部を覆う。font-size: 16.26px font-weight: 600 letter-spacing: 0.1626px border-radius: 2px の組や #3860BE は全部 CMPで、サイトの値ではない
