ウェイトは 300 / 400 / 500 / 600 / 700 の 5 段。既定は 500。300 は社是の 4 語（独立自営・素志貫徹・至誠信実）だけ、700 はヒーローなど 2〜7 要素しかない。ウェイト 100 / 200 / 800 / 900 は @font-face が無いので要求しない。

font-feature-settings は 2 ページとも 0 要素。効かないのではなく、効くのに使っていない（実スタック・32px / weight 700 で実測 normal 971.48px → "palt" 887.77px ＝ −8.6%、"halt" 907.48px、"pwid" 1003.48px）。足すと <span> で手組みした見出しの改行が崩れる。

03 / Numbers
By the Numbers

単位の書体に注意する

数値は 60px / weight 600 / letter-spacing: 3px（0.05em）、単位は <small> の 32px / weight 600。ただし実サイトはこの <small> に --font-en-unit を当てている。

Figtree も Outfit も CJK を持たないので、「年」「億円」は OS ローカルの書体に落ちる。実サイトを CDP の CSS.getPlatformFontsForNode で測ると、年 → Hiragino Kaku Gothic ProN（＝ system-ui）、億円 → Hiragino Kaku Gothic ProN、% → Figtree、同じブロックの 拠点 → Noto Sans JP。1 つの数値ブロックの中で 3 つの書体が混ざり、OS が変われば和文の単位の字面も変わる。

このプレビューでは和文の単位に --font-jp を当て直してある（<small class="jp">）。--font-en-unit は % のような記号だけに限ること。

05 / Vertical Writing
Vertical

下層の章見出しだけ縦組み

トップは 0 要素、下層（/at_a_glance/）に vertical-rl が 12 要素。欧文（Outfit）も縦に流しているので、短い語だけに使う。

About Niterra
どんな会社？
日本特殊陶業は、セラミックを核にした素材・成形・焼成の技術で、自動車・半導体・医療・環境エネルギーの各分野に製品を届けています。

章見出しは 欧文が左（left 160）・和文が右（left 192）で、親は素の flex（row）。DOM 順は欧文 → 和文。縦の和文は 32px / weight 500 / line-height: 1.05 / letter-spacing: 0.96px（0.04em）、欧文は 20px / weight 400 / line-height: 1.00 / letter-spacing: normal。

社是のように「縦組みを横に並べる」ときだけ flex-direction: row-reverse にする。実測では 4 つの語が left 1164 → 1065 → 966 → 868 と右から左へ置かれている。素の flex だと DOM 順に左→右へ並び、日本語の縦組みとして読む向きと逆になる。
