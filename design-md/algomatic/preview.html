サイズには 2 つの系統がある。見出し・本文・カードは rem で viewport に連動し、ナビ・ボタン・チップは px 固定（12 / 13 / 14px）。UI 部品はどの画面幅でも同じ大きさにする設計。
字間も同じ考え方で rem 宣言。em で書くとサイズに比例してしまい、「本文の字間は絶対値」という設計が崩れる。例外は 40px を超える大見出しだけで、そこは 0.08em（ヒーローも h2 もちょうど 8%）。

06 / Guidelines
Do's and Don'ts

やること・やらないこと

Do

  • html { font-size: calc(100vw / 170) } を先に置く。全トークンがこれ前提
  • 見出しは ten-mincho-antique 700。落ちる先は明朝（Hiragino Mincho ProN）
  • 本文・UI は游ゴシック体。和文の Web フォントは読み込まない
  • 字間は rem で宣言（本文 .064rem / タグ .024rem / ボタン .028rem）
  • 40px 超の大見出しだけ letter-spacing: 0.08em ＋ palt
  • 巨大な欧文は -0.02em と逆に詰める
  • 赤は #f8444d 1 色。本文色は #16171d
  • ナビ・ボタン・チップの font-size は px 固定

Don't

  • 見出しをヘビーゴシックにしない（実体は明朝アンチック）
  • nexa の font-weight: 300 を使わない（unloaded）
  • 本文の letter-spacing を em で書かない
  • カード・ボタンに box-shadow を足さない（静止時 0 要素）
  • グラデーションをフラットにしない（ノイズ 24% が前提）
  • アクセント色を 2 色目にしない
  • #fafafc を面に使わない（実サイトでは未使用）
  • フォーム以外に slate の値を持ち込まない
