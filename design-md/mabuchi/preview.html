07 / Line Height & Forms

行間比 1.5 は全幅で動かない

--LINE_HEIGHT: 1.5（単位なし）が 可視 175 要素中 165 要素に当たります。1440px の 16px / 24px も 375px の 14px / 21px も 比率は 1.50 のまま。letter-spacing は全要素 normal です。

08 / Don't

やってはいけないこと

.html ページのレガシースタックを真似しない。ヒラギノ角ゴ Pro W3 先頭・html: 10px・#555555・#0077cc は 2 世代が同居しているだけで、設計として残すものではありません。
#0166b4 を使わない。旧世代にだけ出る 1px ずれた青です。正は #0166b3。
font-weight: 600 を使わない。Google Fonts が 400/500/700 の 3 本なので 700 で描画されます。
box-shadow を足さない。実測 0 種です。
font-feature-settings: "palt" を足さない。CSS 全文に 1 件も無く実測も 0 件ですが、書体は対応しています（実スタック 24px / 400 で normal 2563.14px → "palt" 2243.94px ＝ −12.5%）。「できるのにやっていない」型なので、足すと既存と字送りが変わります。
rem を直接書かない。--FONT_SIZE_N トークン経由にします。なお z-index トークンの綴りは実サイトのまま SERCH です（既存 CSS を編集するときはこの綴りに合わせてください）。
