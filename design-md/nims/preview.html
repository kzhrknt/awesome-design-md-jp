01 / Two modes

Light & Dark

30 個のトークンのうち 25 個が差し替わる

@media (prefers-color-scheme: dark) が CSS 全文に 73 ブロックあります。body { background-color: var(--color-base); color: var(--color-text) } の 2 行だけで、地色は #fff → #222222、文字は #333333 → #E2E2E2 に反転します。下の 2 枚は実測値を固定で並べたものです。

06 / Components

Blur only

影はぼかしだけで offset は 0

実測は rgba(0,0,0,.1) 0 0 10px（7 要素）と rgba(0,0,0,.7) 0 0 10px（5 要素）の 2 種。真下に落とさず四方に均等に広げます。ダークでは地が暗いぶん alpha を 0.1 → 0.7 まで上げて輪郭を立てています。
