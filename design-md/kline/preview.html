01 — ROOT

1rem = 17px。16px で計算すると全部ずれる

html { font-size: 17px }。1920 / 1440 / 1200 / 1024 / 834 / 768 / 767 / 375px の 8 幅すべてで 17px から 1px も動かない。body { font-size: inherit } でそのまま降り、body > * { font-size: 1rem } が受ける。16px でも 10px でも 62.5% でもない。
