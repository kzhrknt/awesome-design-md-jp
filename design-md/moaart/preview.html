03 / Weight

400 と 500 だけ。700 は合成太字になる

document.fonts で loaded なのは Zen Old Mincho の 400 と 500、 秀英角ゴシック銀の normal と 500、Cardo の 400 だけ。 700 の @font-face はどの書体にも無い。 実サイトの h1（32px）と h3 には UA 既定の bold が残っていて、 そこだけブラウザが太らせている。

04 / Letter-spacing

字間は 0.05em と 0.025em の 2 値だけ

しかも em を各要素に当てている。14px→0.7px、20px→1px、24px→1.2px、40px→2px と サイズに比例して px が変わる（すべて 0.05em）。本文系だけ 0.025em（16px→0.4px、14px→0.35px）。 body から px を継承させる設計ではない。
