### 3.3 font-family 指定

```css

  'Yu Mincho', /* Windows用 */
```

**実サイトにある 2 つの誤り（並記）**:

1. **`YuGothicM` は宣言されていない別名。** `@font-face` が CSS 全文に 0 件なので、この名前は**必ず外れる**。Windows 向けの保険のつもりだが機能していない。ただし先頭の `"游ゴシック Medium"` が当たるので実害は小さい。**正しくは `@font-face { font-family: YuGothicM; src: local("Yu Gothic Medium") }` を書くか、別名ごと落とす**
2. **ゴシックのスタックなのに受け皿が `serif` のものがある。**
   ```css
   /* 実サイト（誤り） */ font-family: "游ゴシック Medium", YuGothic, YuGothicM, serif;
   /* 正しくは */        font-family: "游ゴシック Medium", YuGothic, sans-serif;
   ```

   游ゴシックが無い端末では、**ゴシックのつもりが明朝で出る**

## 7. Do's and Don'ts

### Do（推奨）

- **Web フォントを読み込まない。** 游明朝（`YuMincho, "Yu Mincho", serif`）と游ゴシック Medium の 2 本で組む
- **読み物・見出しは明朝、ナビと補助はゴシック**に分ける
- 字間は **`0.15em` / `0.2em` / `0.25em` / `0.5em` の 4 段**から選ぶ。英字の副題は `0.5em` まで空ける
- **角丸と影を使わない**（トップは radius 0 種・shadow 0 種）
- 面は `#9b83af`、ボタンと強い文字は `#745490`、地は `#f1eef5`
- ルートは 16px（UA 既定）、`body` は 13px

### Don't（禁止）

- **ヒーローの大きな文字を HTML テキストで組まない。** 実サイトは `<canvas>` に 2D 描画している（DOM 上の最大テキストは 26px）。**しかも属性 1080×620 を CSS で 1440×827 に拡大しているので、真似すると文字が甘くなる**
- **`font-feature-settings: "palt"` を足さない。** 游ゴシックでは −6.05% 効いてしまい、既存の字送りが崩れる
- **ゴシックのスタックの末尾に `serif` を置かない。** 実サイトに `"游ゴシック Medium", YuGothic, YuGothicM, serif` があるが、これは誤り（正しくは `sans-serif`）
- **`YuGothicM` を `@font-face` 無しで書かない。** 実サイトは宣言が無いので必ず外れる
- **`line-height` の `em` 宣言を無単位に書き換えない**（`1.667em` / `1.92em` / `2.5833333em` は絶対 px として子へ降りる）
- **`letter-spacing` を `em` で親に書いて子に継承させない。** 13px の親の `0.25em` が 8px の子で 0.406em に化ける
- `background-image: url(clear.gif)` を全要素に撒かない（IE 時代の名残）
