TYPEFACE

UD フォント 1 本で全部を組む

和文も欧文も数字も BIZ UDPGothic（モリサワの UD フォント）。フォント要求は 3 件・すべて自社ホスト（/static/fonts/BIZUDPGothic-Regular-Subset.woff2 など）で、外部 CDN を使わない。

★ CSS に @font-face が 1 行も無い。
CSS 全文（4 枚・402,296 文字）を grep しても @font-face は 0 件。それでも 3 本が loaded になる。 正体は static/js/modules/LoadFonts.js の FontFace API。
new FontFace('BIZ UDPGothic', 'url(/static/fonts/BIZUDPGothic-Regular-Subset.woff2)', {…})
CSS を grep しても出てこないので、「Web フォント未使用」と誤読しやすい。判定は document.fonts とフォント要求の件数で行う。

メディアクエリはレンジ構文

@media print, screen and (width >= 768px) { }

@media print, screen and (width >= 1360px) { }
@media print, screen and (768px < width < 1200px) { }

min-width ではなく width >= 768px のレンジ構文で書かれている。print を必ず併記し、ホバーは (any-hover: hover) でガードする。
モバイルの設計幅は 375px（--CONTENT_WIDTH_SP: calc(375px - calc(8px*2)*2) = 343px から読める）。1200px / 1360px はレイアウトだけを変え、文字サイズは動かさない。
