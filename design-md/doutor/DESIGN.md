### 3.2 欧文フォント

- **サンセリフ**: **Roboto**（Google Fonts・実測 31 要素）。日付・`NEWS` `DOUTOR RECRUIT SITE` などのラベル
- 游ゴシックのスタックには `"SF Pro Text"` が 2 番目に入っている（Apple 端末の欧文用）

### 3.3 font-family 指定

```css
/* 本文・ナビ・UI */
font-family: "Yu Gothic", "SF Pro Text", "Hiragino Sans", sans-serif;

/* コピー・大見出し */
font-family: "Yu Mincho", "Hiragino Mincho ProN", serif;

/* 欧文ラベル・日付 */
font-family: Roboto, sans-serif;
```

**このスタックは Windows の游ゴシック問題に対応していない。** `"Yu Gothic"` を直接指定しているため、**Windows では Regular（細い）が当たる**。`@font-face` による Medium の別名割り当ても無い。**正しくは次のどちらかを足す**:

```css
/* 案1: Medium を Regular より前に置く */
font-family: "游ゴシック Medium", "Yu Gothic Medium", "Yu Gothic",
             "SF Pro Text", "Hiragino Sans", sans-serif;

/* 案2: 別名で上書きする */
@font-face { font-family: "YuGothicM"; src: local("Yu Gothic Medium"); font-weight: 400; }
```

### 3.4 宣言されているが 1 バイトも読まれていない Web フォント

**`YakuHanJP`（約物だけのサブセットフォント）が `@font-face` で 100 / 200 / 300 / 400 / 500 / 700 の 6 ウェイト宣言されているのに、どの要素の `font-family` にも書かれていない。**

- `document.fonts` の状態は 6 本とも **`unloaded`**
- フォントファイルの要求は **全ページで 1 件**（Roboto のみ）。YakuHanJP は**ダウンロードすら発生していない**
- `distributions.fontFamily` にも YakuHanJP を含むスタックは **0 件**

**約物（「」（）、。）の詰めを狙って仕込んだ設計が、呼び出し側に書かれないまま残っている。** 実装するなら本文スタックの先頭に置く:

```css
font-family: YakuHanJP, "Yu Gothic", "SF Pro Text", "Hiragino Sans", sans-serif;
```

## 8. Responsive Behavior

### ルートの 2 段構え（ここが最大の落とし穴）

```css
html { font-size: 10px; }                           /* 基底 */
@media (min-width: 769px) { html { font-size: 0.588235vw; } }  /* = 100vw / 170 */
@media (max-width: 768px) { html { font-size: 2.41546vw; } }   /* = 100vw / 41.4 */
```

**実測（7 幅）**

| 幅 | `html` | `body` | 本文 line-height | `letter-spacing` |
|----|--------|--------|------------------|------------------|
| 1440px | 8.47059px | 15.2471px | 27.4447px | 0.152471px |
| 1200px | 7.05882px | 12.7059px | 22.8706px | 0.127059px |
| 1024px | 6.02353px | 10.8424px | 19.5162px | 0.108424px |
| 834px | 4.90588px | 8.83059px | 15.8951px | 0.0883059px |
| **769px** | **4.524px**（最小） | 8.14px | — | — |
| **768px** | **18.5507px** | **29.6812px** | 53.4261px | 0.296812px |
| 375px | 9.05797px | 14.4928px | 26.087px | 0.144928px |

- **769px → 768px の 1px をまたぐと 4.1 倍に跳ぶ。** 過去に収録したどのサイトより大きい崖
- 設計幅は、**デスクトップ側が 1700px**（`0.588235vw` が 10px になる幅）、**モバイル側が 414px**（`2.41546vw` が 10px になる幅）

- **崖は規定の 4 幅（1440 / 1200 / 834 / 375）に入らない。** 必ず 769 / 768 を測る

- **メディアクエリで個別に `font-size` を直す必要がない。** ルートが動くので全部が追従する
- 例外はヒーローコピー（`3.125vw`）。これはルートとは別の係数で動く
