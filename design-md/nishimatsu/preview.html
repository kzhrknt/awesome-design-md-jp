02 / Font stacks
4 つのスタックと、2 つの事故

スタックは 1 語ずつ読む

① 本文（可視 153 / 93 要素）
游ゴシック体, YuGothic, 游ゴシック, "Yu Gothic", "ヒラギノ角ゴ Pro", "Hiragino Kaku Gothic Pro", メイリオ, Meiryo, Osaka, Arial, "ＭＳ Ｐゴシック", "MS PGothic", sans-serif
② 数字の強調（可視 8 / 6 要素） — generic がクォートされている
実サイト: Arial, Helvetica, "sans-serif" ← 引用符を付けると「sans-serif という名前のフォント」を探す指定になり、generic family として扱われない。Arial も Helvetica も無い環境ではブラウザ既定に落ちる
正しくは: Arial, Helvetica, sans-serif
③ html への宣言 — 受け皿なしの 1 語スタック
html { font-family: "Hiragino Kaku Gothic ProN" } ← 解決されるのは html / head / title / meta という不可視要素だけ。body のスタックに上書きされるため可視 0 要素。新規実装では要らない
④ IR ウィジェット（ssl4.eir-parts.net）— 外部ベンダー由来
メイリオ, Meiryo, "ヒラギノ角ゴ Pro W3", "Hiragino Kaku Gothic Pro", "ＭＳ Ｐゴシック", arial, helvetica, clean, sans-serif ← メイリオ先頭のレガシースタック。サイト本体の設計ではないので真似しない
游ゴシックのスタックに Medium が 1 つも入っていない。游ゴシック体 → YuGothic → 游ゴシック → "Yu Gothic" の順で、游ゴシック Medium / Yu Gothic Medium がどこにも無い。body { font-weight: 500 } なので Windows では 500 が游ゴシック Regular に解決されて細く出る。太さを揃えるなら:
① スタック順で解く（東京オペラシティ AG 方式）— "游ゴシック Medium", "Yu Gothic Medium" を YuGothic より前に置く
② 別名方式（SmartHR / 白鶴）— @font-face { font-family: YuGothicM; src: local("Yu Gothic Medium") } を作ってスタック先頭に置く
③ 上書き方式（カリモク）— @font-face で "Yu Gothic" の font-weight: 500 に Medium をマッピングする
