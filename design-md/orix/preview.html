01 — FLUID

ルートは固定。流体なのは要素側

html { font-size: 62.5% } ＝ 10px は 8 幅すべてで固定。にもかかわらずトップページは文字サイズ・字間・gap・角丸まで vw で動く。正体は clamp(12px, N vw, 9999px) ——上限は 9999px ＝事実上なし、下限は 12px。式の分母から設計幅は 1920pxと分かる。
