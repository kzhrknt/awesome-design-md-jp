06 / Notes

Pitfalls

このサイトを読むときの落とし穴

CSS 変数は 1 個しか無く、その 1 個が使われていない。
:root { --leading-trim: calc((1em - 1lh) / 2) } が唯一の宣言ですが、var(--leading-trim) の呼び出しは CSS 全文で 0 回。CSS の lh 単位でハーフレディングを打ち消す式を定義したまま、1 要素にも当てていません。「このサイトのトークン」として引用しないでください。
color 分布の第 2 位 rgba(0,0,0,0) は透明な文字ではない。
56 要素ありますが、これはナビの 1 文字ずつを -no0 -no1 … の span に割ったホバーアニメーションの初期状態です。実際には黒で描画されます。
Roboto SemiBold だけ .ttf 直で woff2 が無い。
他の 2 本は woff2 / woff / ttf の 3 形式を並べているのに、SemiBold は truetype 1 形式のみ。.ttf は woff2 の 2〜3 倍重いので、再現するときは woff2 を用意してください。
