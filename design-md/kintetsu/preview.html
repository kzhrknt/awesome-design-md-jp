CSS Custom Properties は 0 個。色も余白も生値で書かれている。トークンが無いこと自体が実装の実態なので、再実装ではこのページの変数のように名前を与えて使う。

02 / Typography

太字を使わない

font-weight は 400（114 要素）と 500（42 要素）だけ。700 は 1 要素も無い。@font-face も Noto Sans JP の 400 / 500 の 2 本しか読み込んでいない。階層はサイズと色で作る。字間は body に 0.04em を 1 回書いて継承させる（実測 0.64px が 147/156 要素）。

行間は 1.60 と 1.30 の 2 値。読ませる文章が 1.60（103 要素）、一覧・ナビ・リード文が 1.30（43 要素）。「一覧は詰める、文章は空ける」という切り分けで、中間の値を作らない。

字間は継承。body の 0.04em（＝16px × 0.04 = 0.64px）が 147 要素に降りてくる。14px の要素も 44px の見出しも 0.64px のまま。「サイズ × 0.04em」で計算し直すと別物になる。例外は下層の p 2 要素（0.56px ＝ 14px で再宣言）と、カルーセルの Previous / Next（normal・9 要素）だけ。

font-feature-settings: "palt" が 846 要素（下層 699 要素）。本文・ナビ・フッターまで全面適用。palt ＋ 0.04em の組み合わせがこのサイトの字送りで、片方だけでは再現できない。
