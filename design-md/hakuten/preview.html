02 / Tokens

TOKENS

--vw<N>px ＝ 設計 px を名前に、値は vw

CSS 変数 78 個のうち約 72 個がこの形。分母はデスクトップが 1440px、_s 付きのモバイルが 375px。サイズも余白も字間も、全部ここから取る。

:root {
  --vw18px:   1.25vw;        /* 18 ÷ 1440 × 100 */
  --vw48px:   3.333333vw;    /* 48 ÷ 1440 × 100 */
  --vw56px:   3.888888vw;
  --vw18px_s: 4.8vw;         /* 18 ÷ 375 × 100 */
  --vw40px_s: 10.666666vw;
}
body { font-size: min(var(--vw18px), 18px); }   /* = min(1.25vw, 18px) */

html は 19 幅すべて 16px で固定。流体は body 側で作る。html だけ測ると「完全固定のサイト」に見えるので注意。
--vw* を px に読み替えないこと。読み替えると 1440px 以外の幅で全部ずれる。

easing もトークン化されている（:root にある唯一の非サイズ変数）。--easeOutExpo / --easeOutQuint / --easeOutCirc / --easeInOutCirc の 4 つから選ぶ。
