影は offset 0 0 / blur 10px で方向を持たない。ドロップシャドウではなく「浮いている面」の合図として使われている。カードや CTA に影を足さないこと。

ルートは 16 幅すべて固定。html { font-size: 62.5% } = 10px、body { font-size: 1.6rem } = 16px が 1920〜320px で 1px も動かない。変わるのは要素単位の px の階段だけで、769 → 768px で h1 が 67px → 39px、h2 が 57px → 35px、p が 19px → 15px になる。1rem = 10px なので、値 ÷ 10 で px が読める。

ほぼすべてのメディアクエリに print が入っている（print, screen and (min-width: 769px) が 784 件）。印刷時はデスクトップのレイアウトで出る設計。
