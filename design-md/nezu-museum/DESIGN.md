# DESIGN.md — 根津美術館（Nezu Museum）

> 根津美術館（https://www.nezu-muse.or.jp/）のデザイン仕様書。
> 1941 年開館、東京・南青山。東武鉄道の社長を務めた実業家・初代根津嘉一郎の日本・東洋古美術コレクションを基礎とする私立美術館。国宝『燕子花図屏風』（尾形光琳）を所蔵する。2009 年に**隈研吾**設計の本館が竣工し、竹垣に沿う長いアプローチが館の顔になった。
> 最大の特徴は、**サイト全体が明朝体で組まれていること**。`body { font-family: "Noto Serif JP" }` が起点で、ゴシック（Noto Sans JP）は**日付・ナビ・表組みという「読ませない情報」だけ**に使われる。古美術館としての品位を、色ではなく書体の選択で作っている。
> ブランド色は **金茶 `#aa855a`** の 1 色だけ。チケット購入 CTA・現在言語・展示室ラベル・**フォーカスリング**がすべてこの色。
> 組版の要点は 2 つ。ひとつは **`body` が 13px 基準で、文字サイズを全部 % で積むレガシー手法**（`124%` = 16px、`404%` = 52px）。もうひとつは **可変フォントの重みを 100〜700 まで全域使う**こと（本文は `600`、大見出しは逆に `300` や `100` へ**細く**なる）。
> 実サイトの computed style 実測（2026-07-30 取得。トップ＋開催中の展覧会＋美術館について）に基づく。

## 1. Visual Theme & Atmosphere

- **デザイン方針**: **明朝体・白地・金茶 1 色。影は 1 つも使わない。** ファーストビューは隈研吾の竹垣アプローチの写真で全面を占め、UI は写真の上に白文字を置くだけ。下層ページは白地に明朝の 1 カラム。**装飾を足さず、書体と余白だけで格を出す**
- **根津美術館について**: 私立美術館として**展覧会の会期と開館状況が最優先**。ファーストビューの下端に「日付パネル（黒地）＋本日の開館状況＋チケット購入（金茶）」の 3 連が固定され、休館中は「Attention」の半透明白パネルが写真に重なる。**庭園を持つ館なので「いまの庭園」という季節のコンテンツがトップに常設される**
- **密度**: 低密度。作品名・寸法・時代といった古美術のメタ情報は表組みに追い出し、本文は明朝で 1.7 の行間でゆったり流す
- **キーワード**: Noto Serif JP（明朝）全域、金茶 `#aa855a` 単色、影ゼロ、radius 3〜4px、13px 基準の % ラダー、可変フォント 100〜700
- **特徴**:
  - **明朝が既定、ゴシックが例外**。`body` は `"Noto Serif JP", serif`。`"Noto Sans JP", sans-serif` に切り替わるのは **① グローバルナビ ② 会期の日付（`2026年8月15日（土）～10月12日（月・祝）`）③ カレンダーの表組み ④ 開館情報のリスト** だけ。**「数字と操作はゴシック、言葉は明朝」**という切り分け
  - **文字サイズが全部パーセント**。`body { font: 13px/1.231 arial... }` というリセットが 13px を敷き、そこに `124%` / `139%` / `154%` / `170%` / `185%` / `216%` / `247%` / `262%` / `293%` / `372%` / `404%` を積む。**YUI Fonts 系の古典的な手法**で、`16px` と思っている本文は実際には `16.12px`（13 × 1.24）。実測値が `18.07px` `20.02px` `22.1px` `32.11px` `52.52px` のように端数だらけになるのはこれが理由
  - **可変フォントの重みを両方向に振る**。自己ホストの `NotoSerifJP-VariableFont_wght.woff2`（`font-weight: 200 900`）を使い、**本文の既定が `600`**。そこから小見出しは `700` へ太らせ、**大きな見出しは `300`、国宝名などの特大表示は `100` へ細らせる**。「大きい字ほど細く」という明朝組みの定石を可変フォントで実装している
  - **`box-shadow` がサイト全体で 1 つも使われていない**。奥行きは写真・半透明の白パネル・黒帯だけで作る
  - **角丸は 3px と 4px の 2 段**。チケット購入ボタンは `3px`、詳細リンクは `4px`。日付パネルに隣接するボタンだけ **片側だけ丸める**（`border-radius: 0 3px 3px 0`）
  - **フォーカスリングがブランド色**。`:focus-visible` で文字色・ボーダー・背景がすべて `#aa855a` に変わる（`outline` は使わない）
  - **カレンダーで曜日を色分けする**。土曜 `#003f8c`（紺）、日曜・祝日 `#a60000`（臙脂）。**和暦カレンダーの慣習的な配色**をそのまま Web に持ち込んでいる
  - CSS Custom Properties は **0 個**。すべて実値で書かれている

## 3. Typography Rules

### 3.1 和文フォント

- **明朝体（既定）**: **Noto Serif JP**。自己ホストの可変フォント。**サイトの既定書体はこちら**
- **ゴシック体（限定）**: **Noto Sans JP**。自己ホストの可変フォント。**ナビ・日付・表組み・開館情報のみ**

```css
/* 自己ホストの可変フォント（原典の @font-face） */
@font-face {
  font-family: "Noto Serif JP";
  src: url("/common/fonts/NotoSerifJP-VariableFont_wght.woff2") format("woff2");
  font-weight: 200 900;      /* 可変軸 */
  font-style: normal;
  font-display: swap;
}
@font-face {
  font-family: "Noto Sans JP";
  src: url("/common/fonts/NotoSansJP-VariableFont_wght.woff2") format("woff2");
  font-weight: 100 900;      /* 可変軸 */
  font-style: normal;
  font-display: swap;
}
```

- **Google Fonts ではなく自己ホスト**。1 リクエストで全ウェイトが載る可変フォントなので、100〜700 を自由に使える設計になっている

### 3.2 欧文フォント

- **専用の欧文フォントを持たない**。`NEZUCAFÉ` `Attention` `MENU` `JP / EN` などの欧文は **Noto Serif JP / Noto Sans JP 内蔵の欧文グリフ**で組む
- **等幅**: 定義なし

### 3.3 font-family 指定

```css
/* 既定（明朝） */
body {
  font-family: "Noto Serif JP", serif;
  font-weight: 600;
  line-height: 1.7;
  color: #333333;
}

/* ゴシックに切り替える箇所（ナビ・日付・表組み・開館情報） */
font-family: "Noto Sans JP", sans-serif;
```

**フォールバックの考え方**:
- **和文単独指定 + generic family のみ**。游明朝・ヒラギノ明朝への段階的フォールバックは持たない
- 可変フォントの読み込みが失敗した場合は OS の `serif`（macOS: ヒラギノ明朝 / Windows: MS P明朝）に落ちる。**`font-display: swap` なので初回描画は代替書体で出る**
- 実装で移植する場合、フォールバックを足すなら `"Noto Serif JP", "Hiragino Mincho ProN", "Yu Mincho", serif` の順を推奨

### 3.5 行間・字間

- **本文の行間**: **`1.7`**（`body` で全域に指定）。`30.72px / 18.07px` `27.40px / 16.12px` `54.59px / 32.11px` がすべて 1.7 で一致する
- **見出しの行間**: `1.0`（52.52px のトップ見出し、28.08px の h3）／ `1.5`（h5・特大作品名）／ `1.3` `1.4` `1.6` `2.5` も部分的に使う
- **字間**: **既定は `normal`**。字間を入れるのは**ページタイトル（h1）と記事タイトル（h2）だけ**で、`letter-spacing: 3px`

| 対象 | letter-spacing | em 換算 |
|------|----------------|---------|
| h1（32.11px） | `3px` | `0.093em` |
| h2（38.09px） | `3px` | `0.079em` |
| h2 サブ（24.06px） | `3px` | `0.125em` |
| その他すべて | `normal` | — |

- **`3px` を px で固定しているので、字が小さいほど相対的な字間が広くなる**。24.06px のサブタイトルでは `0.125em` に達する。移植時は em に読み替えず px のまま持ち込むと再現しやすい

### 3.6 禁則処理・改行ルール

```css
word-break: normal;
overflow-wrap: break-word;
line-break: strict;
```

- 展覧会名は「はじめての古美術鑑賞」／「―美術のなかの文字―」のように **`<span>` で意図的に 2 行に割る**。自動折り返しに任せない
- 作品名に含まれる `　`（全角スペース）を区切りに使っている箇所がある（`竹雀図　`）。**トリムせずそのまま出す**

### 3.7 OpenType 機能

```css
font-feature-settings: normal;   /* 全域 */
```

- **`palt` を一切使っていない**。明朝体を等幅のまま流し、字詰めは行わない。**約物のアキがそのまま残るのが根津美術館の字面**
- 見出しの詰まりは `palt` ではなく `letter-spacing: 3px`（＝逆に開ける）で調整している

### 3.8 縦書き

該当なし（横組みのみ）。

### Focus

```css
/* テキストリンク */
:focus-visible { color: #aa855a; text-decoration: underline; }

  border: 1px solid #aa855a;
```

## 5. Layout Principles

### Spacing Scale

CSS 変数を持たないため、実測値から読み取れる刻みは以下。

| Token | Value |
|-------|-------|
| XS | `2px` |
| S | `5px` |
| M | `10px` |
| L | `15px` |
| XL | `20px` |
| XXL | `25px` |
| 3XL | `50px` |
| Section | `80px` / `90px`（フッター上下） |

- **5px 刻み**が基本。4px グリッドではない

### Container

- Max Width: 明示的な `max-width` を持たず、`width: 100%` ＋ 左右パディングで構成する
- Padding (horizontal): `15px`（モバイル）〜 `80px`（デスクトップのフッター実測）
- ファーストビューは**フルブリード**（写真が viewport 全面）

### Grid

- 展覧会・コレクションは 2〜4 カラム。下層の本文は 1 カラム
- カレンダーは `<table>` の 7 列（曜日）

## 6. Depth & Elevation

**`box-shadow` はサイト全体で 1 つも使われていない。**

| Level | Shadow | 用途 |
|-------|--------|------|
| 0 | `none` | **すべての要素** |

奥行きは以下で作る。

| 手法 | 値 | 用途 |
|------|----|------|
| スクリム | `rgba(0, 0, 0, 0.35)` | ファーストビュー写真の上（ナビを読ませる） |
| 濃いスクリム | `rgba(0, 0, 0, 0.5)` | 言語切替の周辺 |
| 半透明の白パネル | `rgba(255, 255, 255, 0.8)` | **休館告知**。写真を透かす |
| 黒帯 | `#333333` | 日付パネル・フッター |

- **「浮かせる」のではなく「透かす」**。古美術館らしい、紙や障子に近い階層表現

## 7. Do's and Don'ts

### Do（推奨）

- **本文・見出しは明朝（Noto Serif JP）で組む**。これがこの館の第一の性格
- **ゴシック（Noto Sans JP）は日付・ナビ・表組み・開館情報に限る**。「数字と操作はゴシック、言葉は明朝」
- **`body` の既定ウェイトを `600` にする**。明朝の `400` では画面上で細すぎる
- **大きな見出しはウェイトを下げる**（52.52px → `300`、特大の作品名 → `100`）
- `line-height: 1.7` を本文の既定にする
- **字間は h1 / h2 のみ `letter-spacing: 3px`**、他は `normal`
- 文字サイズは **13px 基準の %**（`124%` = 16.12px…）で積む。移植時は端数を丸めない
- 影を使わず、スクリムと半透明パネルで階層を作る
- カレンダーの土曜 `#003f8c` / 日曜・祝日 `#a60000` を守る
- **フォーカスは `#aa855a`**（色 + 下線、または面の反転）

### Don't（禁止）

- **`font-feature-settings: "palt"` を追加しない**。原典は全域 `normal`。字詰めを入れると明朝の字面が変わる
- **文字色に純黒 `#000000` を使わない**。`#333333`
- **金茶 `#aa855a` 以外のブランド色を持ち込まない**。有彩色は金茶とカレンダーの曜日色だけ
- **`box-shadow` を追加しない**（1 つも使われていない）
- **角丸を 4px より大きくしない**。ピル（`9999px`）は使わない
- **バッジに角丸を付けない**（`radius: 0`。丸いのは「本日」マーカーだけ）
- 緑 `#597d52` を成功色として使わない（`重要文化財` 等の指定区分専用）
- Swiper 既定の `#007aff` を流用しない
- `letter-spacing: 3px` を本文に広げない（読みづらくなる）

## 8. Responsive Behavior

### Breakpoints

**`max-width` ベース（デスクトップファースト）**。段が多い。

| Query | 用途 |
|-------|------|
| `max-width: 1600px` | ワイド調整 |
| `max-width: 1400px` | 大型デスクトップ |
| `max-width: 1200px` | デスクトップ |
| `max-width: 1024px` | **小型デスクトップ / タブレット横。見出しを 1 段落とす** |
| `max-width: 940px` | タブレット |
| `max-width: 768px` | **タブレット縦。主要な切り替え点** |
| `max-width: 650px` / `640px` | スマホ横 |
| `max-width: 520px` | スマホ |

### フォントサイズの調整

**見出しだけを % の段で落とし、本文は動かさない。**

| 要素 | 1440px | 1024px | 768px |
|------|--------|--------|-------|
| h1 | 32.11px (`247%`) | 28.08px (`216%`) | 22.1px (`170%`) |
| h2 | 38.09px (`293%`) | 34.06px (`262%`) | 28.08px (`216%`) |
| h3 | 28.08px (`216%`) | 24.05px (`185%`) | 20.02px (`154%`) |
| 本文 p | **16.12px（不変）** | 16.12px | 16.12px |

- **本文は全ブレークポイントで `16.12px` のまま**。行間だけ 1.7 → 1.74（`28px`）に微調整される
- `clamp()` / `vw` は使わない。**すべてメディアクエリの段切り**

### タッチターゲット

- チケット購入ボタンは `padding: 25px 20px` で高さ 70px 以上を確保
- 詳細リンクは `15px 20px` ＋ `18.07px × 1.7` で高さ約 61px
