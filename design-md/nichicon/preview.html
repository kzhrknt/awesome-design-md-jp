01 / Letter-spacing

ONE DECLARATION

字間の宣言は CSS 全文でただ 1 箇所

.l-main { letter-spacing: 0.05em } だけで、本文 16px に対する 0.8px という絶対値が 57 要素へ px 継承されます。.l-main の外にあるヘッダー・フッターは normal（55 要素）。「本文領域だけに字間を配る」設計で、body に書く流儀とは配り先が違います。このページのヘッダーとフッターにも字間が付いていないことを確かめてください。

em 宣言 → px 継承なので、サイズが違っても字間は 0.8px のまま。
18px の製品カード名では 0.044em、54px の見出しでは 0.015em に薄まります。さらに body の font-size は 768px 以下で 14px に切り替わるので、モバイルでは字間も 0.7px になります。字間を px で直書きすると、この追従が壊れます。
