03 / Type scale

行間は無単位の 2

line-height: 2 は無単位なので 各要素が自分のサイズで再計算する（16px → 32px、15px → 30px）。letter-spacing と継承のしかたが逆なので、行間を px で書かない・字間を em で配らない。

07 / Responsive

html は 10px 固定、body だけ落ちる

html { font-size: 62.5% } ＝ 10px が 1920〜374px の 10 幅すべてで動かない。切り替わるのは body だけで、境目は max-width: 959px。規定の 4 幅（1440 / 1200 / 834 / 375）では 1024 と 834 の間の崖を見落とす。

幅htmlbody font-sizeline-heightletter-spacing
1920 / 1440 / 1200 / 1024px10px16px32px0.64px
834 / 768 / 767 / 414 / 375px10px15px30px0.6px

line-height: 2 は無単位なので比率のまま追従し、letter-spacing: .04em は 0.64 → 0.6px と再計算される（宣言は em、継承は px）。
