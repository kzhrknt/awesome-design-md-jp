01 / The One Declaration
Body

body に1行書いて、1191 要素に効かせる

このサイトに CSS Custom Properties は両ページとも 0 個。色もサイズもハードコードされている。代わりに body の 1 宣言が変数の役割を果たしていて、ここに書いた 4 つが全要素へ降りていく。「変数が無い＝設計が無い」ではない例。

body {
  font-family: "Noto Sans JP", sans-serif;
  line-height: 1.8;                 /* ★無単位。各要素が自分のサイズで再計算する */
  font-feature-settings: "palt";    /* ★実測 1191 要素（horizontal-tb のみ） */
  letter-spacing: .05em;            /* ★16px → 0.8px が全子孫へ px で降りる */
}

ヒーローのコピーは実テキスト（画像ではない）。高める、つくる、 が 72px / weight 700、そして、 が 40px / weight 500、支える。 が 72px に戻る。1 文の中でサイズとウェイトを変えるのがこの見出しの組み方で、字間は全体に 9px（＝ 72px では 0.125em、40px では 0.225em 相当）。

04 / palt
詰めてから、わずかに空ける

palt と letter-spacing はセットで使う

font-feature-settings: "palt" を body に 1 行書いて 1191 要素へ継承させている（実測はすべて horizontal-tb。縦組みを使っていないので、軸の取り違えは起きていない）。その上から .05em をわずかに足し直す二段構えで、片方だけ再現すると別物になる。

05 / Letter Spacing
em 宣言 → px 継承

小さい文字ほど字間が広く見える

body { letter-spacing: .05em } は 16px に掛かって 0.8px という絶対値になり、そのまま子孫へ降りる。サイズに比例しないので、13px の要素でも 24px の要素でも 0.8px のまま。
