05 / Letter Spacing
em 宣言 → px 継承

0.6 / 0.7 / 0.8px の 3 値は「サイズ別」ではなく「親別」

実測値は 3 つに割れるが、サイズごとに em を当て直しているのではない。12px / 14px / 16px の箱がそれぞれ 0.05em を宣言し、そこから px が子へ降りている。

06 / Font Weight
効くのは 500 と 600 の 2 段だけ

700 を当てても DB（600）で出る

document.fonts に載っている dnp-shuei-gothic-gin-std は 500（M）と 600（DB）の 2 本だけ。CSS が 700 を指定している 15 要素は、CSS フォントマッチングで 600 に解決される。本文の既定は 500（実測 169 要素で最多。400 は 26 要素しかなく、そのほとんどが tt-commons-pro の日付）。

太さで差を付けられるのは 500 → 600 の 1 段だけ。「もっと太く」は作れないので、階層はサイズ・色・縦組みで付ける。
