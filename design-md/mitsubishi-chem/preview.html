body { line-height: 20px } は比率ではなく絶対値。宣言し直さない要素には 20px の行送りがそのまま降りる（10px の文字なら比率 2.00、14px なら 1.43）。無単位に書き換えると別物になる。

字間は全要素 normal（可視 149/149 要素）。例外は上の h1 だけで 0.4em。中間の値（0.02em〜0.1em）が 1 つも無いという、極端な二択の設計。

使われていない @font-face が 4 本ある。-Hiragino と -YuGothic は local() だけで OS 書体に別名を付ける方式で、-YuGothic の 400 が local("YuGothic-Medium") を先頭に置いているのは Windows の游ゴシック問題を正しく解いた書き方。しかし font-family にこの別名を書いている要素が 1 つも無く、CSS 全文に 8 回出るだけで機能していない。

07 / Layout & Responsive
Layout

ルートは 2 段、完全固定

vw も clamp() も使わない。帯の中では 1px も動かない。切り替わるのは 768px の 1 本だけで、モバイルの方がルートが大きい（10px → 12px）。

画面幅htmlbodyh2
1920〜834px10px（font-size: 62.5%）10px16px
768〜360px12px（font-size: 75%）12px16px

同じ宣言が !important 付きでもう 1 組ある（html { font-size: 62.5% !important } / 75% !important）。2 世代の CSS が同居している。CSS には body { font-size: 1.6em } 1.2rem といった旧世代の宣言も残っているが、実測の body は 10px。宣言ではなく実測値に従うこと。

文字サイズ拡大機能

ルートは動かさず、body にクラスを足して本文ラッパー 1 か所の font-size を 112.5% にする。CSS 全文に font-size: % が 62 箇所あり、ラッパー配下がこの倍率に連動する。px で直書きするとこの機能が壊れる。
