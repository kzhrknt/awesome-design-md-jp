ウェイトごとに font-family のスタックを別名で差し替える。 700 の要素は … "游ゴシック Bold", "Yu Gothic Bold" …、400 の要素は … "游ゴシック Medium", "Yu Gothic Medium" …。 Windows では font-weight と別名の両方で太さを指定することになり、400 側も Medium に当たって細くなりすぎない。

Adobe Fonts の秀英角ゴシック金を読み込んでいるのに、1 文字も描画されていない。 dnp-shuei-gothic-kin-std は document.fonts で 2 本とも loaded、実ファイルも use.typekit.net から 2 件ダウンロードされ、 CSS 全文に 108 回書かれている。だがスタックの位置が游ゴシックより後ろなので、游ゴシックがある環境では絶対に到達しない。 CDP の CSS.getPlatformFontsForNode で実描画書体を取ると、和文要素はすべて YuGothic。 秀英角ゴシック金を使いたいなら Inter の直後（游ゴシックより前）に置く。

palt は実際に効いている。body に 1 行書いて 759 要素（下層 262 要素）へ継承させている。 実スタック・40px・weight 700 で測ると normal 1040.63px → "palt" 929.44px（−10.68%）、"halt" は 960.63px（−7.69%）。

字間は body に 0.05em を書いた上で、各コンポーネントでも 0.05em を宣言し直す。 その結果 letter-spacing の実測値がサイズに比例して並ぶ （12px→0.6px / 13px→0.65px / 14px→0.7px / 15px→0.75px / 16px→0.8px / 18px→0.9px）。 body の継承だけに頼ると 0.8px が絶対値で降りてしまい、小さい文字で字間が広く・大きい文字で狭くなる。
