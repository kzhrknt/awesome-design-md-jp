font-feature-settings: "palt" を足さないこと。実サイトは CSS に 1 件も書いておらず、しかも足しても効かない。実スタック・100px で 「あア亜永い組設計展」（株）１２３ＡＢＣ、。・ を測ると normal 2300.00px → "palt" 2300.00px（±0.00）、"halt" も 2300.00px。配信されている .woff 版 Noto Sans JP が palt テーブルを持っていない。

本文に康熙部首を混ぜないこと。実サイトの下層本文には ⾏ U+2F8F（4 回）/ ⾒ U+2F92 / ⽬ U+2F6C の計 6 文字が混入しており、同じページの見出しは正しい「銀行」（U+884C）という状態になっている。字形はほぼ同じで目では気づけないが、検索・コピー・読み上げが壊れる。

06 / Layout & Responsive

ルートは 16 幅すべて固定Layout

コンテナはトップ 1060px（6 要素）、下層 870px（7 要素）。ブレークポイントは 767px / 768px が主で、ほかに 1130px と 450px。

container 1060px（トップ・6 要素）
container 870px（下層・7 要素）
breakpoint 767px（max-width 340 件）

1920 / 1440 / 1200 / 1024 / 992 / 991 / 834 / 769 / 768 / 767 / 600 / 481 / 480 / 414 / 375 / 320px の 16 幅すべてで html: 16px / body: 16px / line-height: 24px。vw も clamp() も % の入れ子も無く、1px も動かない。変わるのは要素単位の px の階段だけで、768 → 767px で h3 が 22px → 18px、a が 14px → 11px になる。rem を使っても追従しないので、レスポンシブは @media の px 書き換えで作る。

実サイトの html { font-size: 16px !important } は真似しないこと。!important 付きの px 固定なので、ユーザーがブラウザの文字サイズ設定を変えても本文が追従しない。body 側の font-size: 16px; font-size: 1rem という二重宣言も 1 行にまとめてよい。
