実スタック・56px で実測すると、見出しが 616.00px → 535.42px（-13.08%）、約物だけの文字列が 672.00px → 513.53px（-23.58%）。ヒーローは「palt で詰めた上から 0.28em の字空けを足す」二段構えで、片方だけ再現すると別物になる。

word-break: break-all が body に入っている。日本語の禁則処理を無効にして、行末で熟語の途中でも折り返す指定。製品名や型番が長く並んでも行があふれないが、本文の読みやすさは落ちる。真似する前に確認すること。

和文 Web フォントは 1 バイトも読み込まれていない。Noto Sans JP / Noto Serif JP の @font-face が CSS 全文に 886 件あるのに、フォント要求は Poppins の 2 件だけ。実描画は游ゴシック（CDP で全要素 YuGothic）。さらにスタックに "游ゴシック Medium" / "Yu Gothic Medium" が無いまま font-weight: 500 を可視 77 要素に当てているので、Windows では 500 が Regular に落ちて macOS と太さが揃わない。このプレビューでは Medium を補ってある。
