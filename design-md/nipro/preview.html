02 / em nesting
サイズの単位

サイズはすべて em。入れ子で掛け算になる

CSS の font-size 宣言は 0.5em / 0.55em / 0.75em / 0.875em / 0.93em / 1.08em / 1.125em / 1.25em / 1.375em / 1.75em / 2em / 2.25em / 2.5em … と em ばかり（rem は 0 件、% は 100% の 2 件のみ）。

独自の製品・技術で 医療現場の声に応える。

h3 { font-size: 2.312em } → 16 × 2.312 = 36.992px
strong { font-size: 1.35em } → 36.992 × 1.35 = 49.9392px
端数は流体でも % 入れ子でもなく、em の掛け算。8 幅すべてで動かない。

em 宣言の字間は px で子へ降りる。h3 { letter-spacing: .03em } は 36.992px に対して 1.10976px という絶対値になり、そのまま strong（49.9392px）へ降りる。結果、同じ 1 行の中で親 0.03em・子 0.0222em と実効字間が違う。このプレビューでは strong にも letter-spacing: .03em を書き直している。

サイズを rem に書き換えないこと。親子関係（h3 2.312em → strong 1.35em）が壊れる。
