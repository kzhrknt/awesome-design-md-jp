em 宣言は px で子へ降りる

font-feature-settings は 1 要素も使っていない（両ページとも 0 件）。ただし游ゴシックでは palt が −6.05% 効く（実測 1123.20px → 1055.28px）。「効かないから使っていない」のではなく「効くのに使っていない」ので、足すと別物になる。

実サイトの 2 つの誤り（並記）:

05 / Responsive
Responsive

ルートは宣言なしの16px

CSS 全文に html { font-size } が 1 件も無い（＝UA 既定の 16px）。body は 13px で、1920〜320px の 19 幅すべてで 1px も動かない。h1 / h2 / h3 / p も全幅 13px のまま。流体も clamp() も崖も無い。

ブレークポイントは print, screen and (max-width: 1080px) と print, screen and (max-width: 747px)。print, を併記するのがこのサイトの癖で、印刷時もタブレット幅のレイアウトになる。

ヒーローは <canvas>。「新しい文化を創りだす / BUNKA GAKUEN」の大きな文字は DOM に存在せず（ヒーロー帯の最大テキストは 26px）、2D コンテキストに描画されている。しかも属性 1080×620 を CSS で 1440×827 へ拡大しているので、実機では文字がやや甘い。

html / body / ほぼすべての div に background-image: url(clear.gif)（1×1 の透明 GIF）が当たっている。IE 時代の名残で、再現しないこと。
