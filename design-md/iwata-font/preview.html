letter-spacing は normal が 103/104 要素。字間トークン（--tracking-tight: 0.02em / --tracking-normal: 0.04em）はあるが、実装に出るのは CTA の 0.56px（= 14px × 0.04em）1 要素だけ。書体の字面に任せるのが、書体屋の構え。

font-feature-settings は 2 ページとも 0 要素。書体側の字面設計をそのまま見せるのが狙いなので、palt を足さないこと。書体メーカーのサイトで詰め組みをすると、書体の素の姿が分からなくなる。

@font-face は 108 本宣言されているが loaded は 8 本だけ。残り 100 本（みんなの文字ゴ… I-OTF-UDゴ表示Pr6N… 等）はフォント見本を表示するための在庫宣言。@font-face の本数を「使える書体の数」と読まないこと。

太さは合成で作られている。@font-face はどちらの書体も font-weight: normal でしか宣言されていないのに、CSS は 700 を 34 要素・500 を 35 要素に当てている（＝ブラウザの合成太字）。再現するときは、書体名で太さを切り替えられる書体を用意するか、実ウェイトを持つ書体に差し替える。

影は1つも使わない

08 / Layout
Layout

コンテナ 1284px / カード 384px

--innerWidth: 1228px という宣言はあるが、実測のコンテナ幅は 1284px（5 要素）と 1440px（3 要素）が多く、1228px は 1 要素だけ。カード 1 枚は 384px、列の gap は 38px。

1440px（実測 3 要素）
1284px（実測 5 要素で最多）
--innerWidth: 1228px（宣言。実測 1 要素）
カード 384px（実測 6 要素）

変数名の綴りが --innerPadingInline（d が 1 つ足りない）。実サイトのままなので、このサイトの CSS に追記するときはこの綴りに合わせる。新規に書き起こすなら --inner-padding-inline に直す。

ブレークポイントは (min-width: 992px) が 357 回で圧倒的に最多。768 / 992 / 1200 は Bootstrap 系の列で、モバイルファースト（min-width 優先）で分岐の実質的な軸は 992px 1 本。ホバーは (any-hover: hover) で出し分け、--hover-opacity: 0.8。
