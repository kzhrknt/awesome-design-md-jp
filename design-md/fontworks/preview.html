Generated from fontworks.co.jp DESIGN.md — awesome-design-md-jp / computed style 実測値（2026-08-15）
実サイトの書体は 既定 "Tsukushi Gothic"（筑紫ゴシック）、 UI "UD Kakugo Small"（UD角ゴ_スモール）、 KV タグ "Tsukushi Mincho"（筑紫明朝）。 いずれも自社書体のドメイン配信のためローカルでは表示されない。 ここでは Zen Kaku Gothic New（筑紫ゴシック）／BIZ UDPGothic（UD角ゴ_スモール。同じ UD 系）／Shippori Mincho（筑紫明朝）で代替している。 font-feature-settings: "chws" も代替書体では効かないため、実サイトの約物の詰まり方とは異なる。
