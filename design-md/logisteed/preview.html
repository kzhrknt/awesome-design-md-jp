03 / Font Weight

可変フォントを読んで、2 段しか使わない

Google Fonts から Noto+Sans+JP:wght@100..900 の可変フォントを読み込んでおり、実測でも 9 ウェイトすべてが別の字幅を返します（100 → 1198.61px ／ 900 → 1374.70px、100px の欧文で測定）。それでもページに出るのは 400 と 700 だけ。下のグレーの段は「指定すれば出てしまうが、このサイトには存在しない」太さです。

04 / Line Height

密度は行間だけで作る

body に letter-spacing: 0 と明示的に書いてあり、可視 85 要素すべてが normal。そのうえで line-height を 1.8（既定）→ 2（1025px 以上）と上げます。どちらも単位なしなので比率が子へ降ります。

line-height: 2 — ★実サイト（≥1025px）

09 / Don't

実サイトにあるが真似しないもの

Urbanist — Google Fonts の URL に family=Urbanist:wght@100..900 と書かれているのに、fonts.gstatic.com からのダウンロードは 0 件、可視も 0 要素。CSS だけ取得して捨てています。
Adobe Fonts（Typekit kit ybx7oxu） — @import で読み込み、use.typekit.net と p.typekit.net に毎ページ 2 リクエストが飛びます。中身の source-han-sans-japanese / hero を使うのは別サブサイト（LOGISTEED CAFE）だけで、コーポレート面の可視は 0 要素。
font-feature-settings: "palt" — CSS 全文に 2 箇所ありますが、どちらも .service_logisteed_cafe_wrap の中で、コーポレート面の実測は 0 件。書体自体は対応しており（実スタック 24px / 700 で normal 2576.86px → "palt" 2273.36px ＝ −11.8%）、「できるのにやっていない」型です。足すと既存と字送りが変わります。
