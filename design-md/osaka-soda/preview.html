01 / Letter-spacing

One token

字間は 0.06em を 1 トークンで全要素に配る

var(--text-letter-spacing) の参照は CSS 全文で 45 回。body に書いて px で継承させるのではなく、各要素が em を持ち直すので、サイズに比例して値が変わります。0.06em を px に読み替えないでください。px にすると 22px の見出しと 12px の注記で同じ値になってしまいます。

02 / Font

Dead stack

スタックが途中の sans-serif で死んでいる

実装のスタックは "Zen Kaku Gothic New", "Hiragino Kaku Gothic ProN", "Hiragino Kaku Gothic", メイリオ, Meiryo, sans-serif, YuGothicM, "游ゴシック Medium", YuGothic, "Yu Gothic", -apple-system, "system-ui", "Helvetica Neue"。6 番目の sans-serif がどんな文字にも必ずマッチするため、それ以降の 7 語に一生たどり着きません。わざわざ @font-face { font-family: YuGothicM; src: local("Yu Gothic Medium") } を宣言しているのに、その別名も死んでいます。

body に書いてあるスタックと、実際に当たるスタックが別物です。 body の宣言は YuGothicM, "游ゴシック Medium", YuGothic, "Yu Gothic", -apple-system, …（Zen Kaku Gothic New が入っていない旧世代）で、その上から別セレクタが Zen Kaku Gothic New 先頭のスタックを 106/114 要素に当てています。body の宣言を読んで書体を判断すると間違えます。

正しくは sans-serif をスタックの末尾に 1 回だけ置いてください。いまの並びでは Windows の游ゴシック Medium 対策がまったく効かず、Zen Kaku Gothic New が落ちてこなかった環境ではメイリオに落ちます。

03 / Colors

One red

赤は #DF003A の 1 色だけ。黒は 2 つある

07 / Responsive

Nav only

root も body も固定なのに、グローバルナビだけが vw 流体

html: 10px（62.5%）／ body: 18px（1.8rem）は 1920〜374px で 1px も動きません。ところがナビの文字だけが max(12px, 1.0588vw)（= 設計幅 1700px で 18px、下限 12px）。fontSize 分布に 15.2471px という端数が出るのはこれが原因で、字間も 0.914824px（= 0.06em）と追従します。
