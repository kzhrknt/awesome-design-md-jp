03 / Font Weight

400 と 500 の 2 段しか存在しない

Google Fonts の URL は Noto+Sans+JP:wght@400;500。実測でも字幅は 100〜400 → 1267.30px ／ 500〜900 → 1297.22px の 2 面だけ（100px の欧文で測定）で、font-weight: 700 を当てても 500 で描画され、合成太字も起きません。

06 / Forms & Elevation

唯一の影は「ぼかし 0 の下線」

サイトで見つかった box-shadow は rgba(0,19,55,.5) 0 16px 0 0 の 1 つだけ。ぼかし 0・offset-y 16px で、浮かせるためではなく下線を引くために使っています。

07 / Don't

やってはいけないこと

font-weight: 700 以上を使わない。Google Fonts が 400 と 500 しか配信しておらず、500 で描画されます（合成太字も起きません）。
明朝を Noto Serif JP 等に差し替えない。このサイトは意図的に OS ローカルの游明朝に任せています。差し替えると字面が別物になります。
border-radius と box-shadow を足さない。角丸は両ページとも 0 種、影は下線代わりの 1 つだけです。
letter-spacing を配らない。サイト全体で「寄附」の 4px 1 要素だけです。
font-feature-settings: "palt" を足さない。游明朝 28px の実スタックで normal 2550.00px → "palt" 2194.70px ＝ −13.9% と効く書体ですが、実装は "liga" 1 が 5 要素だけで palt は 0 件。「できるのにやっていない」型です。
ヘッダー左の縦組みロゴをテキストで組まない。実サイトでは画像です（writing-mode: vertical-rl は両ページとも 0 要素）。
