letter-spacing を em で宣言すると、算出された絶対 px が子へ降りる。<rt> は親の半分のサイズなので、同じ px は 2 倍の em に相当する。実測 6/6 サンプルで ratio は 0.50、字間は 0.30em。363 組すべてでこれが起きている。

実装は .is-ruby-off rt { display: none } の たった 1 行。<rt> の computed は ruby-position: over / ruby-align: space-around / display: ruby-text。ルビ切り替えボタンだけ font-family: "MS Gothic"... でサイトの書体スタックから外れている（rubyful ライブラリの既定が残っている）。実装するなら游ゴシックのスタックに揃える。

Google Fonts の URL は family=Noto+Serif+JP:200,300,400。700 は読み込んでいない。にもかかわらず明朝に font-weight: 700 を当てた要素が 16 個あり、実際は 400 で描画される。太く見せたいなら URL に 700 を足すか、宣言を 400 に直す。

游ゴシック問題には別名方式で対応している（@font-face { font-family: "Yu Gothic"; src: local("Yu Gothic Medium"); font-weight: 100〜400 }）。ただし document.fonts では 300 / 400 / bold とも status: error。macOS に「Yu Gothic Medium」という名前のフォントが無いため外れ、スタックの次に落ちる。Windows では意図どおり当たる。error は「宣言はあるがこの端末に該当 local フォントが無い」の印。
