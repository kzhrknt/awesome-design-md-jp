letter-spacing は em を各要素が持つ型（body から px で継承していない。サイズに比例して px が変わる）。大きい文字ほど em が小さい──64px の見出しは 0.00625em とほぼ normal、20px のカード見出しは 0.04em、14px のラベルは 0.02em。一律の字間を配らないこと。

font-feature-settings: "palt" は 2 ページとも 0 要素。効かないのではなく、効くのに使っていない（実スタック・64px・weight 400 で実測 normal 1934.17px → "palt" 1762.84px ＝ −8.9%）。足すと既存のレイアウトと別物になるので、再現するときも足さない。

pwid が 1 要素だけ残っているが、これは意図ではなく Figma のコピペ。フッターのバナー見出しの CSS が color: var(--Foreground-Low-Emphasis, #525252); leading-trim: both; text-edge: cap; font-feature-settings: "pwid" on になっている。leading-trim と text-edge はブラウザが無視し、変数は定義されていないのでフォールバックの #525252 が効く。再現しないこと。

06 / Layout & Responsive
Layout

1440 と 1120 の二段。ルートは完全固定

全幅のセクションは 1440px、本文カラムは 1120px。gap は 8 / 16 / 24 / 32 / 40 / 80 / 96px と 8 の倍数。

container 1440px — 全幅セクション（トップで 10 箇所）
column 1120px — 本文カラム（下層で 6 箇所）
gap 32px — カードグリッド

ルートは 19 幅すべてで html: 16px / body: 16px 固定。1920 / 1600 / 1441 / 1440 / 1200 / 1026 / 1025 / 1024 / 900 / 834 / 821 / 820 / 819 / 768 / 767 / 600 / 430 / 375 / 320px を測って 1px も動かない。clamp() も vw も rem 連動も使っていない。唯一の変化は 375px 以下で <p> が 18px → 16px に落ちること。

ブレークポイントはモバイルファースト：min-width: 768px（467 / 296 件）と min-width: 1025px（196 / 126 件）が主軸で、min-width: 1441px は全幅セクションの上限処理。820/819px にも 751/750px にも崖は無い（実測で確認）。

縦組みは 2 ページとも 0 要素。writing-mode は全要素 horizontal-tb。word-break は normal。
