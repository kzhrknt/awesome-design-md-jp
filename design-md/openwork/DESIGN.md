## 1. Visual Theme & Atmosphere

- **デザイン方針**: 青一色で面を作り、白いカードを敷き詰める情報密度の高い実用 UI。装飾より一覧性
- **密度**: 高い。本文 13px に `line-height: 1.666`、評価スコアは 11.999px。1 画面にカードが 4〜6 枚並ぶ
- **キーワード**: 和文 Web フォント 0 本、13px 基準の `em`、CSS 変数 0 個、字間 normal 557/561、メディアクエリ 0 件

**このサイトの核心は5つある。**

1. **和文 Web フォントを 1 本も読まない。OS 同梱のヒラギノを `@font-face` で別名にして、ウェイト 2 段を自分で作っている。** CSS 全文の `@font-face` は 4 件だけで、うち 2 件が
   `@font-face{font-family:Hiragino Sans;font-weight:400;src:local(HiraginoSans-w3)}` と
   `@font-face{font-family:Hiragino Sans;font-weight:700;src:local(HiraginoSans-w6)}`。
   **PostScript 名で W3（Regular）と W6（Bold）を名指しして、1 つのファミリー名に 2 ウェイトを束ねている。**
   フォントファイルの実リクエストは **2 件**で、どちらも自社ホストのアイコンフォント（`vorkercon.ttf` / `vorkers-pc-icon.ttf`）。和文は 1 バイトも落ちてこない
2. **サイズをすべて「13px を分母にした `em`」で書く。** `body { font-size: .8125em }`（= 16px × 0.8125 = **13px**）を起点に、各要素が `1.076em` `1.1538em` `1.3846em` … と重ねる。
   実測が `13.988px` `14.9994px` `17.9998px` `11.999px` `10.998px` `16.0004px` `69.875px` のような**半端な端数だらけ**になるのはこのため。**13 で割ると設計値（1.076 = 14/13、1.3846 = 18/13、5.375 = 69.875/13）が出る**
3. **CSS 変数が 1 個も無い。** `:root` にも `body` にも Custom Property の宣言が 0 個。色もサイズも hex と `em` の直書きで、デザイントークンという層が存在しない
4. **字間を設計していない。** `letter-spacing` の宣言は CSS 全文で **12 件**、実測は **`normal` が 557/561 要素**。例外は**ヒーローの大見出し 4 要素だけ `4px`**（69.875px に対して 0.057em）
5. **メディアクエリが 1 件も無い、PC 専用のページ。** 1920 / 1440 / 1280 / 1200 / 1024 / 992 / 991 / 834 / 769 / 768 / 767 / 600 / 480 / 375 / 374px の **15 幅すべてで `html: 16px` / `body: 13px` が 1px も動かない**。`distributions.layout.breakpoints` も空。スマートフォンは別テンプレートで配信される

## 3. Typography Rules

### 3.1 和文フォント

- **ゴシック体**: ヒラギノ角ゴシック（**OS 同梱。Web フォントとして配信していない**）
- **明朝体**: 使用しない
- Windows では `メイリオ` に落ちる。**游ゴシックはスタックに入っていない**

### 3.2 欧文フォント

- 専用の欧文フォントを指定していない。数字も欧文もヒラギノ角ゴシックの従属欧文で組む
- アイコン専用に `vorkercon` / `vorkers-pc-icon` の 2 本を自社配信（`.eot` / `.ttf` / `.woff`。**`.woff2` が無い**）

### 3.3 font-family 指定

```css
/* 実サイトの body 宣言そのまま */
body {
  color: #000000;
  font-family: "Hiragino Sans", ヒラギノ角ゴシック, "Hiragino Kaku Gothic ProN",
               "ヒラギノ角ゴ ProN W3", メイリオ, Meiryo, sans-serif;
  font-size: .8125em;   /* 16px × 0.8125 = 13px */
}

/* ウェイト 2 段を OS 書体から自分で作る（このサイトの要） */
@font-face { font-family: "Hiragino Sans"; font-weight: 400; src: local(HiraginoSans-w3); }
@font-face { font-family: "Hiragino Sans"; font-weight: 700; src: local(HiraginoSans-w6); }
```

- **この 2 本の `@font-face` を省かない。** 省くと `font-weight: 700` がブラウザの合成太字になり、W6 の字面と変わる
- `src` が `local()` だけなので、`document.fonts` 上は **macOS で `loaded`／該当書体の無い環境では `error`** になる。これは異常ではない
- スタック 7 語のうち、実際に当たるのは先頭の `Hiragino Sans`（macOS）か `メイリオ`（Windows）。**CDP の `CSS.getPlatformFontsForNode` でも全要素 `Hiragino Sans` が返る**

### 3.4 文字サイズ・ウェイト階層

**`em` の数値をそのまま書く。px は「ブラウザ既定 16px のときの値」として併記する。**

| 用途 | 宣言 | 実測 px | weight | 実測件数 |
|------|------|---------|--------|----------|
| ヒーロー大見出し | `5.375em` | **69.875px** | 700 | 4 |
| ヒーロー小見出し | `2.846em` | 36.9993px | 700 | 1 |
| セクション大コピー | `2.4615em` | 31.9995px | 400 | 1 |
| セクション見出し (h2) | `1.6923em` | 21.9999px | 700 | 1 |
| リード文 | `1.4615em` | 18.9995px | 700 | 2 |
| 小見出し | `1.3846em` | 17.9998px | 700 | 38 |
| 導線リンク | `1.3077em` | 17.0001px | 700 | 7 |
| カード見出し (h3) | `1.2308em` | 16.0004px | 700 | 10 |
| ボタン | `1.1538em` | 14.9994px | 700 | 42 |
| 数値・スコア | `1.076em` | 13.988px | 400 | 38 |
| **本文** | `.8125em`（body） | **13px** | 400 | 118 |
| 評価軸ラベル | `.923em` | 11.999px | 400 | **191（最多）** |
| タグ・属性 | `.846em` | 10.998px | 400 | 36 |
| 最小 | — | 10px | 400 | 48 |

- **ウェイトは 400 と 700 の 2 段だけ**（実測 389 / 172）。`@font-face` が 2 本しか無いので、**500 や 600 を当てても 400 で出る**
- **本文 13px は意図的な小ささ**。16px に上げるとカードが収まらず、`em` の入れ子がすべてずれる

### 3.5 行間・字間

```css
body { line-height: 1.666; }   /* 無単位。各要素が自分のサイズで再計算する */
```

- 実測の行間比は **1.67 が 509/561 要素**。例外は `1.60`（タグ 18 要素）、`1.50`（ボタン 15 要素）、`1.80`（職種リンク 14 要素）、`1.30`（ヒーロー大見出し 4 要素）
- **`line-height` を px で書かない。** 11.999px から 69.875px まで 14 段のサイズがあり、px で固定すると大見出しが潰れる
- **字間は `normal`。`letter-spacing` を足さない。** 実測 557/561 要素が `normal`。**唯一の例外がヒーローの大見出し 4 要素で `letter-spacing: 4px`**（69.875px に対して約 0.057em）
- CSS には `-13px` `-5px` `-3.5px` `-1px` という大きな負値の宣言もあるが、いずれも可視要素に当たっていない

### 3.6 禁則処理・改行ルール

- `word-break` / `line-break` / `overflow-wrap` の宣言なし。ブラウザ既定の日本語禁則に任せる
- ヒーローの大見出しは `<span>` で 3 行に手割りしている（`転職する？ 社内で磨く？` / `キャリアの選択に` / `確かな情報を。`）。**自動折り返しに任せていない**

### 3.7 OpenType 機能

- **`font-feature-settings` の宣言が CSS 全文に 0 件。** 実測も 0 要素
- ヒラギノ角ゴシックは `palt` を持つので**効かせることはできる**。だが既存のレイアウトは詰めない前提で組まれているので、**後から足すと別物になる**

### 3.8 縦書き

- 縦組みは使用しない（`writing-mode` の実測 0 要素）

## 4. Component Stylings

### Buttons

**面の色と角丸の組み合わせが 3 種類ある。**

```css
/* Primary — 登録導線（緑・ピル） */
.btn-primary {
  background: #3aa131;
  color: #ffffff;
  font-size: 1.1538em;     /* 14.9994px */
  font-weight: 700;
  border-radius: 30px;     /* ピル。実測 48 要素 */
  padding: 8px 24px;
}

/* Secondary — 青の面（角丸 4px） */
.btn-secondary {
  background: #1b7fbe;
  color: #ffffff;
  font-size: 1.1538em;
  font-weight: 700;
  line-height: 24.989px;
  border-radius: 4px;
}

/* Tertiary — 淡い面に黒文字 */
.btn-tertiary {
  background: #f2f6fa;
  color: #000000;
  font-size: 13px;
  font-weight: 700;
  border-radius: 4px;
}
```

- **緑のピルと青の角丸 4px を取り違えない。** ピル（`30px`）は**登録・申込の導線だけ**、角丸 `4px` はそれ以外
- 下層ページの CTA は面を持たず、**白地に `#1b7fbe` の文字 + `border`** になる

### Badges / Chips

```css
.tag { border-radius: 2px; font-size: .846em; line-height: 1.6; }  /* 10.998px */
```

- 面は持たず、**文字色だけで種別を分ける**（中途 `#9a9bc5` ／ 正社員 `#999999` ／ 直接応募 `#c98061` ／ エージェント紹介 `#29a089`）

### Inputs

```css
/* 検索欄とボタンを角丸で連結する */
.search-input  { border-radius: 4px 0 0 4px; }
.search-button { border-radius: 0 4px 4px 0; background: #1579c0; }
```

### Cards

```css
.card {
  background: #ffffff;
  border-radius: 4px;                              /* 実測 65 要素で最多 */
  box-shadow: rgba(0,0,0,.1) 0 2px 4px 0;          /* 10 要素 */
}
```

### ペイウォール（このサイト固有）

```css
/* クチコミの続きを「白い内側の影」で消す */
.paywall {
  box-shadow: rgb(255,255,255) -5px -5px 10px 4px inset;   /* 実測 10 要素 */
}
```

- **グラデーションのマスクではなく、不透明な白の `inset` 影で下端をぼかす**。影 3 種のうちの 1 つがこれ専用

## 6. Depth & Elevation

**影は 3 種類しか無い。** 増やさない。

| 影 | 用途 | 実測 |
|----|------|------|
| `rgba(0,0,0,.1) 1px 1px 2px 0` | 職種リンクのボタン | 14 要素 |
| `rgba(0,0,0,.1) 0 2px 4px 0` | 推薦コメントのカード | 10 要素 |

  **`50% / 100% 100% 0 0` は「上半分だけの半円」**で、セクション見出しのアイコン台座に使う

## 7. Do's and Don'ts

### Do（推奨）

- **`@font-face` で `local(HiraginoSans-w3)` / `local(HiraginoSans-w6)` の 2 本を宣言する。** これがウェイト 2 段の実体
- **サイズは 13px を分母にした `em` で書く**（`14px → 1.076em`、`18px → 1.3846em`）。px に直すと `em` の入れ子が崩れる
- **`line-height` は無単位 `1.666`** を `body` に 1 回だけ書いて継承させる
- 青は **`#1579c0`（ヘッダー）／`#1b7fbe`（面）／`#166c9d`（文字）** を役割で使い分ける
- 登録 CTA は**緑 `#3aa131` のピル（`border-radius: 30px`）**、それ以外は青の角丸 `4px`
- 影は 3 種類から選ぶ。alpha は `.1` 固定

### Don't（禁止）

- **和文 Web フォントを足さない。** Noto Sans JP を読み込むと、13px 基準で組まれた行長と字面が全部変わる
- **`font-weight: 500` / `600` を使わない。** `@font-face` が 400/700 の 2 本しか無く、400 で出る
- **`letter-spacing` を足さない。** 実測 557/561 が `normal`。字間を入れるのは**ヒーローの大見出しだけ（`4px`）**
- **CSS 変数を導入しない。** このサイトには 1 個も無く、色は hex 直書きが実装
- **メディアクエリを書かない。** PC 専用ページで、ブレークポイントが 1 件も存在しない
- **`line-height` を px で固定しない。** 10.998px から 69.875px まで 14 段ある
- **`font-feature-settings: "palt"` を足さない。** 効くが、既存のレイアウトは詰めない前提
- **本文を 16px に上げない。** 13px がこのサイトの基準で、上げると `em` の階層がすべてずれる
