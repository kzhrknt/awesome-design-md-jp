03.6 — word-break

body に word-break: break-all が当たっている

word-break: normal（ブラウザ既定）

新しい価値の創造 Life-changing な毎日へ、りそなは寄り添います。

word-break: break-all（★実サイト）

新しい価値の創造 Life-changing な毎日へ、りそなは寄り添います。

差が出るのは欧文の単語。 normal は Life- / changing で割るが、break-all は Life-changin / g と語の途中で切る。和文だけの例文では両者が同じ結果になるので判別できない。

03.9 — Accessibility

文字サイズ拡大は html のクラス差し替え

文字サイズ
  • 標準
  • 拡大

html の class を jsFontNormal ⇄ jsFontLarge に差し替える。ルート（10px）も body（18px）も動かない。 CSS 側に .jsFontLarge <セレクタ> { font-size: Npx } を 1 つずつ手書きで並べる方式で、 実測すると main は 18 → 24px に増えるのに p は 12px のまま、h2 は 26px のまま置き去りになる。 新規実装では html の font-size を変えて rem で連動させること。
