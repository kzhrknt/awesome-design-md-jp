05 / Guidelines

やること・やらないこと

Do

  • サイト全体を 1 書体（UD明朝）で組む。ナビもボタンも日付も明朝
  • フォールバックを必ず書く（実サイトは 1 語だけだが、明朝に落ちることが設計上不可欠）
  • font-weight は 400 を既定にする。太字で階層を作らない
  • border-radius: 0 を貫く（ドットのみ 50%）
  • 本文色は純黒 #000000、コンテンツの地色は #f5f5f5
  • letter-spacing は normal を既定に、見出しだけ px で空ける
  • 縦組みの見出しは letter-spacing: 6px（0.2em）
  • 予約 CTA の padding は 14px 20px 14px 45px
  • 影は rgba(23, 73, 77, 0.15)（青緑）を数箇所だけ
  • ルビは本文のちょうど半分（14px → 7px）

Don't

  • 見出しをゴシックにしない（ゴシックは定義リスト 20 要素だけ）
  • font-weight: 700 で太さを期待しない
  • font-feature-settings: "palt" を足さない（実測 0 要素）
  • 本文に letter-spacing を足さない
  • border-radius を 4px や 8px にしない
  • CSS Custom Properties を前提にしない（実サイトは 0 個）
  • 影を rgba(0,0,0,…) にしない
  • "Hiragino Kaku ProN" と書かない（存在しない名前。正しくは "Hiragino Kaku Gothic ProN"）
  • 游ゴシックに font-weight: 900 を指定しない（合成ボールドになる）
  • 赤 #ff0000 を汎用のアクセントに使わない
