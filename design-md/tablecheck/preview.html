07 / Elevation

2 層構造 ＋ 負のスプレッド

近い小さな影と遠い大きな影を重ね、どちらも負のスプレッドで要素の外にはみ出させない。

--elevation-small-raised0 1px 2px -1px rgb(0 0 0 / .2),
0 2px 6px -2px rgb(0 0 0 / .1)
--elevation-medium-raised0 1px 4px -1px rgb(0 0 0 / .2),
0 2px 6px -2px rgb(0 0 0 / .1)
--elevation-large-raised0 2px 8px -1px rgb(0 0 0 / .2),
0 2px 12px -4px rgb(0 0 0 / .1)
--elevation-light-small0 0 3px 0 rgba(0, 0, 0, .1)

実測で最も多いのは --elevation-small-raised（14 箇所）。カードは既定で影を持たず、浮くもの（ドロップダウン・ポップオーバー）にだけ当てる。
