03 / Font Weight

500 は読み込まれていない。実際の太さは 2 段しかない

Google Fonts の URL は family=Noto+Sans+JP:wght@400;700。 document.fonts にも 400 と 700 しか載らない。それなのに CSS は トップで 66 要素・下層で 66 要素に font-weight: 500 を当てている。 CSS のフォントマッチングは 500 を要求されたとき 400 → 300 → … → 600 → 700 の順に探すので、 実際には 400 が当たる（合成太字も入らない）。

font-weight: 400 — @font-face あり
名品ギャラリー 2026
★font-weight: 500 — @font-face に無い。左と同じ太さで出る
名品ギャラリー 2026
font-weight: 700 — @font-face あり
名品ギャラリー 2026

500 を「中間の太さ」として設計に組み込まないこと。 本当に中間が要るなら Google Fonts の URL を wght@400;500;700 に増やす。増やすと見た目が変わる。

05 / Multilingual

多言語の一言を &text= サブセットで出す

中国語・韓国語の注意書きを 1 文だけ出すために、その文に出てくる文字だけのサブセットを読み込んでいる。 フォント全体（数 MB）を配らずに、正しい字形で 1 文を見せる実装。

Noto Sans SC / TC / KR — 400 のみ loaded（700 は unloaded）

簡体字・繁体字・ハングルの注意書きを、それぞれ 1 文ぶんの文字だけ読み込む。

読み込み方

?family=Noto+Sans+SC:wght@400;700&display=swap&text=簡体字の注意書きに出てくる文字…

★&text= を付けると、その文字だけの極小サブセットが返る。 多言語の短い文を正しい書体で出したいときに再利用できる実装。
