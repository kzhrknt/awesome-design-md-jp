Line break

字間ではなく、改行で読ませる

可視 216 要素のうち 208 要素が letter-spacing: normal。詰めも開きもしない代わりに、body に 3 点セットを書いて全要素へ継承させている。

body {
  overflow-wrap: anywhere;   /* 長い英単語・URL はどこでも折る */
  word-break: normal;        /* 日本語の分かち書きは既定のまま */
  line-break: strict;        /* 小書き仮名「ゃゅょっ」長音符「ー」も行頭禁止 */
}

line-break: strict は既定の auto より禁則が厳しく、overflow-wrap: anywhere は word-break: break-all と違って日本語の禁則を保ったまま欧文だけ折る。この 2 つはセットで書く。

line-break: auto（既定）/ 幅 236px
持続可能なサプライチェーンとRegenerationをテーマに、ちょっとずつ進める。
line-break: strict　← 実サイト / 幅 236px
持続可能なサプライチェーンとRegenerationをテーマに、ちょっとずつ進める。

左は 3 行目が 「っとずつ進める。」で始まり、小書き仮名の「っ」が行頭に来てしまう。右は「ちょっとずつ」をまとめて次行へ送る。和文だけの例文では差が出ない（既定でもどこでも折れるため）ので、欧文語を挟んで折り返し位置をずらしている。

overflow-wrap: normal（既定）/ 幅 150px
詳しくは https://www.ojiholdings.co.jp/sustainability/ をご覧ください。
overflow-wrap: anywhere　← 実サイト / 幅 150px
詳しくは https://www.ojiholdings.co.jp/sustainability/ をご覧ください。

左は URL が折れず、指定した 150px の幅を無視して右へ伸びる（横スクロールやレイアウト崩れの原因になる）。右はどこでも折る。word-break: break-all でも同じように折れるが、そちらは日本語の禁則まで無効にするので、overflow-wrap: anywhere を使う。
