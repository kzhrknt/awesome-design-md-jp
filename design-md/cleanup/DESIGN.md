## 3. Typography Rules

### 3.2 欧文フォント

- **サンセリフ**: **Inter**（`--en`）。日付・`TOP` `BRAND CONTENTS` などのラベルに **トップ可視 90 要素**
- **手書き**: **Caveat**（`--en_hand`）。**下層の装飾見出し専用**（`Knowledge` `Merit 1.` `Merit 2.` の 4 要素）。トップでは 0 要素
- **フォールバックのみ**: `Arial` が 31 要素あるが、これは Swiper のページネーション（`Previous` `Next` `1`）で、サイトの設計ではない

### 3.3 font-family 指定

```css
/* 本文（和文が先頭） */
font-family: "Noto Sans JP", "ヒラギノ角ゴ ProN", "Hiragino Kaku Gothic ProN",
             メイリオ, Meiryo, sans-serif;

/* 欧文を優先したいラベル・日付（Inter を先頭に差す） */
font-family: Inter, "Noto Sans JP", "ヒラギノ角ゴ ProN", "Hiragino Kaku Gothic ProN",
             メイリオ, Meiryo, sans-serif;

/* 手書きの装飾見出し */

```

**フォールバックの考え方**:
- 和文を先頭に置くのが既定。欧文を立てたい要素だけ `Inter,` を前に差す**差分方式**
- 末尾の `メイリオ, Meiryo` は Windows 向けの受け皿。`sans-serif` が最後に来るので**その後ろに書いても死ぬ**（このサイトは正しく最後に置いている）

## 6. Depth & Elevation

影は実質 **1 種類**しかない。

```css
/* カード・パネル（トップで 37 要素） */
box-shadow: rgba(0, 0, 0, 0.15) 0 0 3px 0;

/* 内側に落とす版（SNS ブロックの 1 要素のみ） */
box-shadow: rgba(0, 0, 0, 0.2) 0 0 3px 0 inset;
```

- **オフセットは 0、ぼかしは 3px、広がりは 0。** 「浮かせる」のではなく**輪郭をわずかに締める**ための影
- 不透明度は 0.15（inset は 0.2）。**色は黒のまま**
- 角丸は **3px / 2px / 100%(円)** の 3 種だけ

### Do（推奨）

## 8. Responsive Behavior

### ルートは完全固定、h2 だけが最小側で流体

`html` も `body` も **12 幅すべてで 16px**。崖も `clamp()` も無い。
ただし **`h2` だけが 480px を境に `4vw` へ切り替わる**（要素側の流体）。

| 幅 | h2 の font-size |
|----|-----------------|
| 1440px 〜 **480px** | **19.2px**（固定） |
| **479px** | 19.16px |
| 430px | 17.20px |
| 415px | 16.60px |
| 400px | 16.00px |
| 390px | 15.60px |
| **375px** | **15.00px** |

**`479 × 0.04 = 19.16` / `375 × 0.04 = 15.00`** でちょうど `4vw`。
**480px で 19.2px に着地するので段差が無い**（崖のない片側流体）。

```css
h2 { font-size: 19.2px; }
@media screen and (max-width: 479px) {
  h2 { font-size: 4vw; }   /* 設計幅 480px */
}
```

> **ルートが固定なので `rem` では追従しない。** 再現するには `vw` を直接書く。

### タッチターゲット

- ヘッダーの高さは PC・モバイルとも `59px`（`--hd_h` / `--hd_h_sp` が同値）
- ボタンの最小高さは 40px 前後
