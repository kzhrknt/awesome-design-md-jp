ただし、その palt が縦組みの 4 要素にも降りている。クロス集計は "palt" @ horizontal-tb 3993 ／ "palt" @ vertical-rl 4。横組み用の palt は縦組みでは黙って無視される（エラーも警告も出ない）ので、右端の固定タブは詰まっていない。このプレビューでは縦タブを font-feature-settings: "vpal" に上書きしてある。

数字のためだけの文字集合サブセット

ウェイトは 300 / 400 / 500 / 700 の 4 段。既定は 500（400 / 373 要素）。700 はヒーローの 12 文字だけ、300 は LANGUAGE / SEARCH / 日本語 の 6 要素だけ。600 は Lexend 専用で、和文に 600 を当てると @font-face に無いので 700 で出る。

letter-spacing は 0.04em が既定（13px → 0.52px が 274 要素で最多）。ヒーローだけ 0.12em（8.16px）と大きく空け、縦組みタブだけ −0.04em と詰める──符号が逆。それ以外は 0.04em か normal の 2 択。

box-shadow はサイト全体で 1 種類・1 要素だけ（rgba(0,0,0,.5) 0 5px 30px＝オープニングのカーテン）。奥行きは 1px solid #d7d7d7 の枠線と #f5f5f5 / #fafafa の面色で作る。

トップと下層でルートが違う（2 世代同居）。トップは html に font-size の宣言が無く UA 既定の 16px、下層は 62.5% で 10px。body はどちらも 15px なので本文の見た目は揃うが、rem の意味が 1.6 倍ずれるので px で書くこと。ブレークポイントも、トップは min-width: 751px 系、下層は max-width: 1259px / max-width: 959px 系と書き方が違う。

html は固定のまま、body だけが 750px を境に vw 流体へ切り替わる。規定の 4 幅（1440 / 1200 / 834 / 375px）では 834px も 375px も素直に見えるので、崖が見えない。
