01 / Fonts

Web フォントを 1 本も読み込まないTYPEFACE

フォントファイルのリクエストは 0 件。document.fonts に載るのは Anton（×3・unloaded）と swiper-icons だけで、本文はすべて OS のローカル書体。この preview も <link> を置かず、実サイトと同じ状態を再現している。

★ 欧文の Barlow は 30 要素に指定されているのに、1 本も宣言されていない。
原因は Google Fonts の URL の書き方。
@import url("https://fonts.googleapis.com/css?family=Anton&family=Barlow:400,600,700&display=swap");
/css?（v1 エンドポイント）に &family= を重ねる v2 の書き方を混ぜているため、返ってくるのは Anton の @font-face 3 件だけで Barlow は 1 件も含まれない。ステータスは 200 なのでエラーにならず、黙って sans-serif に落ちる。 正しくは css2?family=Anton&family=Barlow:wght@400;600;700（v2）か、css?family=Anton|Barlow:400,600,700（v1 の | 区切り）。
