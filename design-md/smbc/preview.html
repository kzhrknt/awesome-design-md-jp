03.9 — Accessibility

文字サイズ切替は html の font-size を動かす

html のクラスを -fsSmall / -fsdDfault / -fsLarge に差し替える。実測は html が 8px / 10px / 12px（×0.8 / ×1.0 / ×1.2）、body が 12.8px / 16px / 19.2px。 本文も 1.6rem なので自動で追従する。選択は Cookie に永続化される。
サイズを px で直書きするとこの機能が丸ごと壊れる。 3.4 節の px 値は「標準（html 10px）のときの値」で、実装は rem で書く。 （クラス名の fsdDfault は実サイトの綴りのまま。Default のタイプミス）

06 — Depth & Elevation

影の色は緑がかったグレー

Level 1 — ナビ
rgba(20,29,29,.05) 0 0 4px 0, rgba(20,29,29,.08) 0 12px 14px 0
Level 2 — カード
rgba(81,127,111,.16) 0 7px 35px 0
Level 3 — グロー
rgba(81,127,111,.25) 0 0 18px 0

Level 2 / 3 の rgb(81, 127, 111) は緑がかったグレー。rgba(0,0,0,…) に置き換えると面の下が灰色に濁り、サイトの印象が変わる。Level 1 だけ本文色 #141d1d を 2 枚重ねる。
